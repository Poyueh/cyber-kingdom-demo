# 第 112 課：讓怪物動作跟著真正的戰鬥走

本次新增的 `data/enemy_cast.tres` 是怪物外觀入口。在 Godot 點開它，可看見一般怪物、抱晶動作、七地守門者與七龍的外觀資源。每份 `data/enemy_appearance/*.tres` 記錄同一張圖集的格子尺寸、腳底基準、步行／蓄力／出手／受創／死亡格子，以及步幅與出手演出時間。

例如森林巨龍的 `windup` 指向四個蓄力姿勢。`presentation/raider_motion_view.gd` 觀察實際剩餘蓄力時間，決定現在畫哪一格；真正的 `dragon_fire` 或 `planet_strike` 事件才啟動爆發姿勢。小怪被重劈打斷時，不會因為蓄力突然歸零就誤播爪擊。

這些資源只決定畫面。調整 `strike_seconds` 可以改收招的視覺節奏，但不會改傷害或安全反擊時間。反擊標記仍讀取原本的戰鬥規則；不要用動畫播完的回呼直接造成傷害。模擬時鐘停止，怪物和碎片也一起停止，讀檔不會補播已發生的攻擊。

練習：先複製 `dragon-forest.tres` 作備份，在 Inspector 將 `idle_fps` 從 4.2 調到 3.5，預覽巨龍待機節奏，再還原。這能練習區分「演出快慢」與「玩法強度」。目前仍沒有你的練習回報，因此學習紀錄不會把這項標成已掌握。

美術原稿在 `art/concepts/devourers-v001`，遊戲讀的是 `art/characters/devourers-v001`。離線工具以每套動作一個固定比例製作原生像素格；不要把每一幀各自縮到填滿格子，否則胸口、頭部和腳會在動畫中忽大忽小。

七地清單保存外觀資源路徑；進入星球時才載入當地兩份圖集。一般怪物與抱晶圖集共用。這次相同原生開局的貼圖用量從整批預載的約 156.7 MiB 降為約 86.7 MiB；它示範 Resource 參考也會影響記憶體生命週期。
