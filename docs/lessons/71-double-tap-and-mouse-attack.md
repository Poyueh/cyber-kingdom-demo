# 71：雙按衝刺與滑鼠攻擊

電腦操作現在是：按住 A／D 一般移動；同一個方向快速按兩次，第二下不放開就衝刺。放開、換方向、同時按兩邊或暫停會解除衝刺。Shift 不再加速。J 與滑鼠左鍵都能揮劍，再按可連斬；按住左鍵不會自動連打。手機維持長拖加速及劍按鈕。

在 Godot 的 FileSystem 點開 `data/desktop_controls.tres`，Inspector 的 **Double Tap Seconds** 控制兩次按下之間可相隔多久，目前 0.28 秒。改成 0.35 會比較容易觸發，改成 0.20 則需要更快雙按。這只影響手勢辨識，不會改變衝刺速度或體力消耗。

輸入辨識放在 presentation/frontier_controls.gd；角色能不能衝刺，仍由 application/campaign_travel.gd 決定。因此雙按也不能繞過耗盡後的停步和恢復限制。作業系統的按鍵自動重複不算第二次按下。

滑鼠攻擊只接收未被介面使用的點擊。Godot 的 Button 會消耗 GUI 事件；TouchScreenButton 則使用另一條觸控事件路徑，所以漢堡選單、手機攻擊鈕、懸空填晶格另共用 HUD 已計算的排除區，避免點選單時揮劍。手機合成的滑鼠事件也不會額外出刀。

喘息滑行的原因是移動已恢復，休息圖卻仍在淡出。現在最後 0.35 秒先在原地收尾，位移恢復前結束休息圖；疲勞計時和存檔格式維持原規則。腿部也提高髖部、伸展支撐腳、降低收腿高度，持劍與空手同步調整。

小練習：暫時把 Double Tap Seconds 改成 0.35，開新旅程比較 A、鬆開、A 按住的節奏，再改回 0.28。雙按後按 Esc，恢復遊戲應保持停止，必須重新按鍵。
