# 第 74 課：方向輸入與攻擊動畫

現在攻擊有兩種：不按方向時原地連斬；按住方向才踏斬。手機左側拖曳與鍵盤方向共用同一規則。

Godot 的 `actor_body.gd` 將方向交給核心。`combatant.gd` 計算這個揮擊時段可前進多少，沒有方向就丟棄該段位移。因此鬆手再按不會突然滑出先前累積的距離。視覺層用相同方向狀態選擇圖集，攻擊進度和命中判定不重播。

在 Godot 開啟 `data/knight_combo.tres`：Return Step Distance 現在同時控制第一、第二刀的方向踏步，Finisher Step Distance 控制第三刀。兩者都只在按住方向時生效；不按方向仍然是原地攻擊。

可練習：在空地先連按 J，再按住 D 連按 J，比較動作和距離；第二次在揮擊中途放開 D，應停止向前推進。這不改目前的存檔格式。
