# 第 79 課：Nearest 不等於像素密度一致

Godot 的 Nearest 只決定縮放時如何取樣，不會自動讓兩張來源解析度不同的圖具有相同顆粒感。

此次新騎士先製成每格 128 × 96、人物約 60 像素高的圖集。預覽放大三倍時，一格像素就成為 3 × 3 方塊，不會出現新的盔甲細節。未來接進 AnimatedSprite2D 時，AtlasTexture 也應裁這份原生圖集，再共用同一顯示倍率。

同一畫布尺寸不代表人物一定一樣高；應比較人物實際佔用像素、腳底錨點和整段動畫的比例。居民可以比騎士矮，但像素顆粒仍要相同。

本次尚未替換正式 Godot 角色。使用者尚未回報操作理解程度，不記為已掌握。
