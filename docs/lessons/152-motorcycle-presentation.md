# 152｜用獨立輪轂做出重機行駛

這次沿用 mount_expedition 的解鎖與存檔狀態，只換呈現資源，因此玩家已付的6晶與取得進度不需要重算。hero_v005_appearance.tres 指向新的160×128圖集，車身每格相同；完整騎士以臀部錨點對齊，避免動作切換時車身或人體變形。

motorcycle_drive.gd 只讀當前速度，以「前進距離 ÷ 輪胎半徑」累積輪轂角度。沒有移動就不轉；相位用fposmod保持有界，暫停delta為0也不會轉動。這是呈現層的責任，不把Node或繪圖寫進純規則層。車庫的無人車則用同一車身底圖，省下重複的狀態和資源。

實際看看：tools/review_motorcycle.gd 在完整戰役場景錄下行駛、轉向、上下車與揮劍。測試解鎖費用、存讀與戰鬥規則仍有效；動畫好不好看則以錄影和實玩判斷。
