# 70：腳底定位、跑步週期與強制喘息

這次的跑步不再使用相似姿勢拼接。將既有盔甲切成腿甲、手臂、上身和披風，離線產製十六格圖集；遊戲只播放圖集，不會逐幀處理圖片。腿部包含落地、蹬地、收腿與騰空，持劍與空手共用腳步節奏。怪物也有連續步態，攻擊則接回原有蓄力及斬擊圖。

在 Godot 點開 `data/travel_recovery.tres`，新的 **Breath Stop Seconds** 控制耗盡時必須停住喘息的秒數，預設 2。其後才慢走；體力回到 30% 可跑步，75% 且停下休息滿 2 秒才可再衝刺。一直按住第二段不能跳過。這個狀態屬於玩法，因此存入 v12 紀錄；暫停時不計時，v11 以前的紀錄仍能升級讀取。

腳底或樹根要對齊的是「圖片中看得見的最下端」，不能只看 PNG 外框。本次遠景樹根略埋入地面，風只影響樹冠，下段樹幹固定；整張森林背景也下移，讓地面蓋住參差的根部。場景植物、石塊及遺跡的高度和搭配用獨立裝飾亂數，避免改變真正的資源分布。

小練習：在新旅程持續長拖或按 Shift＋D，觀察「停住 → 慢走 → 跑步」。等跑步恢復後放開移動，休息再長拖，才會重新衝刺。若想把最初喘息改長，只調 Breath Stop Seconds，不必碰動畫或存檔程式。

換日提示放在 `presentation/dawn_banner.gd`：太陽徽記、細線和天數一起淡入淡出，延用既有三語翻譯；它只負責畫面，不推進遊戲天數。
