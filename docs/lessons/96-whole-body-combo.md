# 第 96 課：動畫的重心與每格時間

這次僵硬的原因在圖格：肩、腰與腿幾乎沒變，只有手臂揮動。增加刀光無法代替身體發力，所以重新畫了蓄力、轉身、承重與收招的完整姿勢。

在 Godot 開啟 data/blacksteel_v004_combo.tres，可以查看三刀的 weights。它決定每一格占這一刀多久：蓄力可稍久，出刀較短，收招再穩住。圖格本身負責姿勢；時間權重負責節奏。數值並不改傷害和移動規則。

觀察重劈：先抬身，接著肩膀與腰一起壓下，前腿承重，再回穩。原地斬固定的是角色在世界裡的位置，不是把圖中的骨盆與雙腳凍住。這次的實錄直接擷取遊戲，與遊戲使用同一份圖集。

本課供對照，尚未以玩家回饋確認掌握程度。
