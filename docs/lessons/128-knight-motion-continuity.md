# 第128課：同一個人物，怎麼接不同動作？

在 Godot 打開 `data/hero_v005_appearance.tres`，它是整套騎士圖片與播放設定的共同入口。`frames` 管待機、走跑與受擊；`combo` 管三段攻擊；`ceremony` 是拔劍的完整姿勢。

先比較待機、走路、受擊三張圖的頭盔、胸腰與腳底位置。即使每段動畫本身流暢，只要換段時人物變大，玩家還是會感覺突兀。因此先把原圖比例畫對，再設定圖格與播放速度。不要用角色節點的 Scale 硬把某一段壓瘦。

本專案的 `presentation/knight_stride.gd` 保存0到1的步態進度，走路改跑步時保留當前換腳位置；停止或暫停時不推進。攻擊則由戰鬥進度選擇圖格，刀刃接觸時機由既有判定決定。調圖片不應偷偷改變傷害或移速。

可自行練習：在安全路段依序待機、走路、連按同方向快跑、停下、出刀。先看腰線是否跳動，再看前後腳是否真正交換。這堂是提供練習，尚未把你的掌握程度標記為完成。
