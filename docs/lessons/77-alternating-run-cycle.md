# 第 77 課：跑步循環要包含左右腳各一次

跑步圖格多，不代表腳步正確。這次原圖有八格，但很多格都是同一隻腳在前，連播便像重複蹬腿。新的預覽用 24 格呈現完整循環：近側腿落地、承重、蹬地、收回；遠側腿晚半個循環做同一組動作。

Godot 的 SpriteFrames 只會播放準備好的圖格，不會自動修正步伐。如果未來套入這張圖集，要設為 6 欄、4 列，依序加入 24 格，36 fps 約每 0.667 秒完成左右兩步。角色速度與腳步節奏仍需在真正移動的場景中對齊；本輪僅更新獨立美術預覽，尚未接入遊戲。

打開預覽選「半速檢視」，再暫停比較第 1 與第 13 格：亮腿與暗腿應輪流跨到前面。逐格滑桿可以確認，不需要先學程式。

玩家接著指出全身不平衡。這提醒我們：即使兩腳確實交替，腿甲被拉長、腰部移位而上身固定，仍會像拼接角色。修正版保留新原圖的腿部比例，讓肩腰、自由手和披風一起參與步伐。看動畫時先看整體重心，再檢查格數；通過程式測試不代表動作好看。

玩家又指出預覽與展示圖片不同，原因是展示的是生成全身圖，預覽卻是拆件重組後的姿勢。現在把兩者分開，預設直接播放原圖裁格，並可開啟原圖比對。未來匯入 Godot 也應先檢查「這格是不是原本核對過的圖」，再處理切格、尺寸、播放速度；不能拿原圖的外觀替重組動畫背書。
