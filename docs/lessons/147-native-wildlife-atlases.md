# 第147課：完整動作圖集與固定腳底錨點

在Godot開啟 `data/wildlife/fox.tres`，Texture現在指向狐狸的八格動作圖集。Frame Size是每格96×80，Columns為4，Ground Pivot的(48,74)表示每格腳底對齊的位置。遊戲只換完整姿勢，不再把身體、腿和尾巴各畫一塊，所以毛皮細節與身體輪廓能保持一致。

`presentation/wildlife_art.gd`將「實際累積移動距離 ÷ Stride」換成走路循環進度，再取出對應一格。停下時距離不再增加，動作也停在當下；不會因為時鐘還在走而原地滑步。轉身只鏡射完整圖，不能分別放大身體與四肢。

原稿很大不代表遊戲就精緻。先用 `tools/prepare_wildlife_art.py` 將同一物種的八格以同一倍率整理成原生像素，檢查實際遊戲尺寸還能否辨識眼睛、耳朵、羽毛及甲殼，再看森林裡的腳底接地和光影。這次保留鹿作為實際對照，不只看放大的原稿。

第146課記錄的是v0.0.69的粗方塊做法；v0.0.70已用本課的完整圖集取代，狩獵規則與存檔不變。
