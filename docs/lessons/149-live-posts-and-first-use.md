# 第149課：據點跟著城牆，教學跟著玩家

這次號令旗沒有保存一份可能過期的城牆座標；每次直接向防線系統取得當前最外側城牆。外牆倒塌時，旗與兵營自然退回內側，讀檔也不會留在舊位置。

在 Godot 開啟 `data/command_rules.tres`，Rally Cost、Repair Cost、Recruit Cost 分別是2、6、4晶；旗幟距離、兵營內縮與隊伍追擊半徑也可在同處查看。數值在建立旅程時解析保存，舊旅程不會被改成另一套費用。

「曾經顯示過提示」和「玩家真的用過功能」是兩種狀態。本次只在成功操作後記下已使用功能；讀檔和航行保留這份記憶。因此玩家還沒做完時可以再問，用過後就不用再教一次。快照v24新增獨立command區段，v23升級時只填空白狀態，保留原有世界。

太空船美術使用內建image_gen生成，再以固定比例整理成384×224原生像素圖集；兩格共用地面錨點，修復切換時船不會浮動。原稿及完整提示在art/concepts/rescue-v001，遊戲只載入art/settlement/rescue-v001/rescue-ship.png。
