# 第 78 課：先看完整跑步姿勢，再補中間格

本輪重新設計八個完整身體姿勢，按左右兩步安排落地、承重、蹬地與换腳。它們是動作關鍵格，並不代表已完成最終精修動畫。若关键姿勢重心不對，只複製圖格或提高播放速度仍不會自然。

預覽的動畫和下方整張圖直接使用同一個 `sources/run-v003.png`。只整體縮放並對齊地面，沒有再拆腿、拉長肢體；這樣可以真正比較畫出的姿勢與播放效果。

未來放入 Godot 時，用 AtlasTexture 指定每格區域，再放入 SpriteFrames；本輪八格以 12 fps 播放，一輪約 0.67 秒。接入前仍要確認循環接點、移動速度與腳步是否一致。目前只更新美術預覽，沒有換掉遊戲內角色。
