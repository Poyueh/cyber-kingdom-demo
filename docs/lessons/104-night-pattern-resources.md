# 第 104 課：用 Resource 調整夜襲的準備時間

在 Godot 的 FileSystem 找 `data/night_patterns.tres`，點選後看 Inspector：First Day 決定何時開始新攻勢，Warning Seconds 是日落前預警秒數，Regroup Seconds 是夾擊的出兵間隔。

先把 Warning Seconds 從 75 改為 90，另開新旅程測試；它代表多 15 秒回防時間，不會多生怪物。既有紀錄保留開始旅程時的設定。測完可以改回 75。

規則在 domain，Resource 供調整，畫面只讀預告，三者各負責一件事。尚未收到操作回饋，不記為已掌握。
