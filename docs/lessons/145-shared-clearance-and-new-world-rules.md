# 第145課：圖像大小與避讓範圍要讀同一份設定

鬼魂原本用80×86的範圍避讓，而且只嘗試固定距離的幾個位置。寬提示框可能擋住全部候選，畫面就把整隻鬼魂藏起來。現在從提示框的四個邊緣找可放的位置，並讓移動與繪製都讀同一份 `body_half_size`。

在Godot開啟 `data/spirit_companion.tres`，Inspector 的 Body Half Size 是(30,34)，表示保留60×68的安全範圍。這是避讓空間，不是縮放圖片；新造型本身使用較小的兩像素網格。圖像重製後要一起確認安全範圍，避免看起來沒碰到按鈕卻突然消失。

`data/wildlife_population.tres` 的 Per Forest 則只會解析到新旅程的設定；舊存檔按自己的數值還原，不會因調整這個Resource而突然多出動物。
