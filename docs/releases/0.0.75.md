# v0.0.75 — 龍晶重機

戰馬改為龍晶重機：固定接地車身、隨行進距離轉動的輪轂、完整騎姿與騎乘揮劍。停下不再繼續馬步，轉向保留輪轂相位；新增短電動機發動與行駛聲。

馬廄改為西側重機車庫，停車會顯示無人重機。森林導流器回收獎勵改為反應爐核心，仍需6晶修復；移速仍+25%、上下車免費，沿用原本戰鬥、夜襲預警與跨星規則，沒有額外燃料消耗。

主遊戲與森林Demo同步，舊存檔已解鎖的坐騎直接換車，不需重買；未完成的導流和修復進度保留，快照仍v24。三語遊戲文字、指南、圖示及企劃規格同步。

主遊戲與Demo各提供macOS、Windows、Web、Android debug APK及待簽署iOS Xcode專案。macOS使用既有臨時簽署；iOS仍需開發者簽署，未宣稱完成手機真機或Windows實玩驗收。
