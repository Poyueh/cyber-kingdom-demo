# Cyber Kingdom v0.0.8 — 步態、衝刺與疲勞恢復

本次更新 H5 瀏覽器版。

- 電腦衝刺改為快速雙按 A 或 D，第二下持續按住；不再使用 Shift。放開或切換方向解除衝刺。
- 新增滑鼠左鍵攻擊，保留 J 與連斬；點擊選單不會誤觸攻擊。
- 調整持劍／空手跑步、衝刺與疲勞慢走，伸展腿部、改善交替落腳與動作銜接。
- 衝刺耗盡先停住喘息 2 秒，期間不能移動；接著慢走、恢復一般跑步，充分恢復並站定休息後才可再次衝刺。起身完成前不再滑行。
- 手機攻擊按鈕加大，拖曳顯示兩段方向箭頭，快慢切換更穩定。
- 修正背景樹根浮空，增加森林裝飾高低層次；改善怪物移動、蓄力、出刀與受擊表現。
- 換日改為淡入淡出的日出徽記，前導加入開場淡入。
- 繁中、簡中、英文操作提示與圖文指南同步更新。
