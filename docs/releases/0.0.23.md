# v0.0.23 — 七星遺物與玩法選配

- 新旅程八件主動部件：森林雷弧／雷槍、沙地磁爪、冰岸冷凝針、沼澤牽引線圈、熔谷工匠脈衝、雷城指揮透鏡、墓環電容；各地探索帶回不同用途。
- 改造所收藏介面顯示用途、來源星球線索和首件／四件／八件里程碑。初次取得免費裝上，八晶換回已收藏部件，仍只有一個槽與共用冷卻。
- 部件有不同圖示、護甲掛件及戰場特效；弓兵下一箭、工匠施工、敵人減速、龍晶回收與騎士漸進充能實際生效。
- 強化存讀與跨星保護；舊紀錄維持原來兩件配置，需開新旅程體驗新增星球獎勵。修正火箭施工時的工作狀態，使在建火箭可正常保存。
- 同步繁中／簡中／英文遊戲文字及圖文 Help。K／雙指上滑使用；營火旁 F／齒輪選配。

此版擴充探索獎勵，沒有宣稱十四種不同謎題已完成。平衡與心流仍需實際玩家試玩。Windows／手機未真機驗收；Android 為 debug APK，iOS 為待簽署 Xcode 專案。
