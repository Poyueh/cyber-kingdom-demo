# 主流程引導，完整遊戲與森林 Demo 分開發行

**Main（完整主遊戲）**：選「開始旅程」直接在自己的營地學會點火、招募、採集和防守。兩夜後保留營地、居民和資源，接著探索森林、封門、屠龍與七星旅程；玩家選擇的旅程節奏保留。

**Demo（對外試玩）**：只提供森林兩夜。其餘六星關卡、遭遇資料、專用敵人及場景素材實體排除，使用獨立名稱、應用身分和存檔，並附三語精簡指南。公開試玩站現在提供此版本。

兩版共用小型龍晶顯示、情境用途費用、免費守軍配置、普攻免費和移動恢復衝刺。引導依實際採集收入、施工和守軍到位推進；隱藏提示不會替玩家完成步驟。準備點完整還原；主遊戲完成兩夜教學後退役，Demo 可繼續重試。舊旅程保留原規則，主遊戲保留舊版應用身分和存檔位置。

## 下載選擇

- 檔名含 **Main**：完整主遊戲，含 macOS、Windows、Web、Android 與 iOS Xcode 專案。
- 檔名含 **Demo**：森林試玩，提供相同五平台，適合分享給試玩者。
- [直接玩森林 Demo](https://poyueh.github.io/cyber-kingdom-demo/?v=0.0.56)
- [遊戲企劃規格書・修訂 37](https://poyueh.github.io/cyber-kingdom-demo/spec/?v=0.0.56)

## 驗證與限制

完整回歸通過，包含 4,565 項既有規則、72 項核心流程、87 項主流程及實際場景檢查。五平台成品內容與存檔隔離逐一驗證；macOS 與 Android 簽章、封裝及校驗碼核對完成。

macOS 為 ad-hoc、未公證；Windows 未簽署；Android 為 debug APK。iOS 附件是待簽署的 Xcode 專案，尚非可直接安裝的 App。Windows、iPhone／iPad／Android 真機、首次遊玩理解度與 10–15 分鐘節奏分布仍待測；匯出及自動測試不代表真人體驗驗收。
