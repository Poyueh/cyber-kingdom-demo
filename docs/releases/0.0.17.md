# v0.0.17 — 騎士全套動作重繪

- 跑步與衝刺各 12 張，重畫前傾姿態、雙腿交錯與披風；持劍／空手分別製作。
- 三段連斬改為斜切、回挑、重劈，各 8 張；原地與跨步踏斬使用不同全身動作。
- 一併重畫待機、疲勞慢走、喘息、受擊、倒地、拔劍與舊紀錄騎乘姿勢。
- 統一遊戲尺寸、腳底基準與部件掛點；預览直接使用遊戲圖格，無需新開存檔。
- 更新繁中、簡中、英文圖文指南與原生連斬示範。

操作不變：A／D 移動，同方向連按兩次並按住第二下衝刺，J／滑鼠左鍵攻擊。手機左右拖曳移動、加長拖曳衝刺、點劍圖示攻擊。無方向時原地連斬，按方向才踏進。

試玩平台：H5、Windows、macOS、Android debug APK；iOS 提供待簽署 Xcode 專案。桌面尚未正式簽署／公證，手機與 Windows 本次未真機驗證。
