# Cyber Kingdom v0.0.11 — 農具工坊與施工防線

這是 `cyber-kingdom-demo` 的第一個公開 Release，提供 H5、macOS、Windows、Android 測試包與 iOS Xcode 專案。

- 營火二級會自動建立農具工坊；玩家投入 2 顆龍晶製造鋤頭，居民只會領取現有工具。
- 城牆與箭塔在建造、升級或修復期間會暫停防禦功能，完成後才恢復；施工棚架會顯示目前狀態。
- 新旅程的居民工作範圍收斂到城牆外約一個畫面，白天工人與獵人仍會在近域採集。
- 過遠的資源不會出現可付款委託；寶箱與特殊部件仍可探索取得。
- 鬼魂指引不會再指向超出可委託範圍的採集目標。

平台說明：

- H5 會由 GitHub Release 事件自動部署到 GitHub Pages。
- macOS 測試包為 ad-hoc、尚未 notarize；Windows 測試包未簽署。
- Android 為 ARM64 debug APK，不是 Google Play 正式簽署包。
- iOS 是待 Xcode 簽署的 Xcode 專案，尚未產生可直接安裝的 IPA。

完整檢查：`bash tools/check.sh` 通過，包含 Godot 匯入、場景、架構、存檔、觸控和平台匯出檢查。
