- 森林西方新增戰馬遺跡：循纜線轉動兩座導流器，解開機關取回核心；沒有倒數，進度可保存。
- 回營地西側花 6 晶修復馬廄，免費上下馬、移動快 25%；坐騎可同行前往其他星球。失劍會下馬，取回劍後可再騎。

- 新旅程巨龍成長在第 14 天封頂，召喚後鎖定；探索不再讓巨龍無限變強。
- 新遺跡／馬廄圖素、能量流向、橘色警訊與繁中／簡中／英文圖文指南。
