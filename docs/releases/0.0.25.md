# v0.0.25 — 找回已賺到的龍晶

- 鬼魂會指向持有龍晶且安全的居民，幫助玩家把採集收入投入下一筆建設。
- 器具、聚落與火箭的建造建議會計入已填入的格數；龍晶不足付完時先找補給，避免反覆投入又退回。
- 採集中、商旅回程與隔日交貨提供不同說明；已知的交貨晶體仍在飛行時，提示會繼續引導收取。
- 修正空袋時略過免費拔劍點火，以及等待封印／交貨卻提示領取器具。
- 三語提示依文字高度排版，避開短暫日出天數；圖文指南同步。
