# v0.0.18 — 刀光與斬擊力道

- 三段斬擊加入青白像素刀光，橫斬、上挑與重劈有不同劍路，最後一刀帶金色刃緣。
- 拉開蓄力、快速出刀與收招的節奏，第三刀更有重量。
- 命中加入接觸火花、短暫停頓和小幅鏡頭推力；揮空維持流暢。
- 停頓中可輸入下一刀，多目標命中不會疊加停頓；無方向原地斬、按方向才踏斬。
- 更新繁中、簡中、英文說明與原生連斬實錄。既有紀錄可直接續玩。

操作：電腦 J／滑鼠左鍵，手機點劍圖示。連續點按接三刀，按住不會自動連打。

提供 H5、macOS、Windows、Android debug APK 與待簽署 iOS Xcode 專案。macOS 為 ad-hoc，Windows 未簽署；手機與 Windows 本次未真機驗收。
