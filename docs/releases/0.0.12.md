# Cyber Kingdom v0.0.12 — 部件工坊與即時裝配

本版將騎士成長調整為探索部件：新部件取得時立即裝上，想換回已找到的部件可回營火旁工坊選擇，費用為 8 顆龍晶。工坊選配不會重置部件冷卻；冷卻完成會有短暫光效。

- 營火二級會自動建立農具工坊；玩家投入 2 顆龍晶製造鋤頭，居民只領取現有工具。
- 城牆與箭塔在建造、升級或修復期間會暫停防禦功能，完成後才恢復。
- 新旅程工人與獵人的採集及委託範圍約為城牆外一個畫面；遠處資源不能委託，寶箱與部件仍可探索取得。
- 騎士部件升級設施改為營火旁部件工坊。取得任何部件前不可互動；探索取得新部件時立即裝配，換裝已取得部件花費 8 顆龍晶。
- 玩家指南與部件操作提示支援繁體中文、簡體中文及英文。

平台說明：

- H5 會由 GitHub Release 事件自動部署到 GitHub Pages。
- macOS 測試包為 ad-hoc、尚未 notarize；Windows 測試包未簽署。
- Android 為 ARM64 debug APK，不是 Google Play 正式簽署包。
- iOS 為待 Xcode 簽署的 Xcode 專案，尚未產生可直接安裝的 IPA。
