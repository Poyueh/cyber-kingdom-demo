# Cyber Kingdom v0.0.7 — 龍晶生存與最後的火光

本次更新 H5 瀏覽器版。建議建立新旅程體驗完整新規則；既有紀錄保留其建立時的部分設定，請勿清除網站資料。

- 龍晶即生存資源：最多 30 顆，受擊先掉晶，空袋後掉劍，再受擊死亡。小怪拿到龍晶會撤退，流浪者拾取龍晶會加入居民。
- 晶袋收支時短暫出現，帶有晶體堆疊與入袋／出袋動態；E／手機下滑可在空地丟晶，建築旁優先投入，Q 可直接丟晶。
- 荒地出發、拔劍點火建立營地；農業於二級營火解鎖，探索可取得特殊部件，帶回騎士設施選配，K／雙指上滑使用。
- 鬼魂完成初期引導後離開；營火旁的引魂壇每次投入 1 顆龍晶召回提示。
- 改善無劍／持劍移動節奏、喘氣及拔劍演出；慢走可恢復體力，快跑與慢走速度差更明顯。
- 太陽與日夜光照、水面倒影、柔化水岸、分層搖曳森林、林間斜光、建築旁 NPC 與跳動營火。
- 25 秒實際遊戲前導演出，包含營火、夜襲與巨龍，可跳過；勝敗改用場景上的敘事文字，繁中、簡中、英文同步。
