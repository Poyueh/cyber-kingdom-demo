# v0.0.24 — 看懂遺跡，解開星球

- 六顆後續星球加入三類機關：沙地／沼澤的連動燈、冰岸／熔谷的冷熱平衡、雷城／墓環的脈衝亮窗；各地初態與參數不同。
- 機關在場景中顯示受影響連線、框選刻度與旋轉指針。靠近 E／手機下滑操作，不另開解謎面板。
- 免费重試，部分進度可保存；脈衝錯拍保留已充能節點、暫停停止倒數。解開後領取該星球原有專屬部件。
- 森林保留入門符序與中繼。舊紀錄保留原來機關，新玩法請開新旅程。
- 同步繁中／簡中／英文提示、圖文 Help 與 Godot 調整教學。

機關是否易懂、探索與回防的節奏仍需真人試玩。Windows／手機未真機驗收；Android 為 debug APK，iOS 為待簽署 Xcode 專案。
