# v0.0.29 — 選擇你的遠征節奏

- 新遊戲可選遠征、拓荒或圍城。拓荒有較長白晝與較少增援；圍城準備時間較短、增援成長較快；遠征沿用原本設定。
- 三種節奏共用七星球、坐騎、機關及完整收藏；設定跟著紀錄保存，跨星與重試不重置。
- 選擇紀錄能辨識旅程節奏；返回選單不建立多餘紀錄。繁中、簡中、英文與圖文指南同步。
- 修正從手動檢查點另存續玩會漏帶其他星球進度的問題，保留當前星球、龍核、採集與完整旅程設定。

舊紀錄維持原規則；本次修正不能還原先前已遺失的星球資料。Windows／手機尚未真機驗收，Android 為 debug APK，iOS 為待簽署 Xcode 專案。節奏平衡仍需真人試玩。
