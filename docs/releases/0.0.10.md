# Cyber Kingdom v0.0.10 — 近域採集與黑鋼騎士完整動作

本次更新同步提供 H5、macOS、Windows、Android 與 iOS Xcode 測試包。H5 會在 GitHub Release 發布後由 Pages 自動部署；桌面包未簽署，Android 是 debug APK，iOS 附件是等待 Xcode 簽署的專案。

- 部件操作改為清楚的三語提示：電腦按 **K** 使用、在營火旁的騎士改造所按 **F** 選配；手機使用雙指向上滑。部件會以小型機械結構自然掛在騎士背甲上，跟隨移動、攻擊、受擊、倒地與騎乘動作。
- 改造所移到營火旁，避免玩家拿到部件後找不到安裝位置；二級營火會自動建立農具生產處，投入兩顆龍晶後居民會自行取用農具。
- 黑鋼騎士全面換成同一套原生像素素材：八格跑步、徒手跑步、衝刺、慢走、待機、喘息、連斬、拔劍、受擊、死亡與騎乘，修正不同狀態像不同角色的問題。
- 工人採完資源會把龍晶留在自己身上，騎士靠近才交付；袋子滿時暫停新採集，溢出龍晶掉在工人腳邊。
- 工人與獵人只會在城牆工作範圍內尋找資源，城牆擴張後範圍即時增加；遠處資源不再出現可付款互動。寶箱和特殊部件仍可由騎士探索取得。
- 舊存檔升級至新的改造所位置，損壞或未知版本仍會安全拒絕載入。
- 三語介面、農具建築識別、部件掛點與原生像素密度同步整理。

建議建立新旅程體驗完整的近域採集規則；舊存檔仍可載入。Windows／macOS 包尚未簽署或 notarize，請在本機安全設定中允許測試程式。

Release 另外提供 `Cyber-Kingdom-iOS-v0.0.10-Xcode.zip`。解壓後用 Xcode 開啟 `CyberKingdomDemo.xcodeproj`，選取你的 iPhone 或 iPad 後按 Run；第一次需要讓 Xcode 向 Apple 建立裝置 provisioning profile。此附件尚未簽署、未產生 IPA，也尚未送 App Store Connect。

Release 另外提供 `Cyber-Kingdom-Android-v0.0.10-debug.apk`。這是 ARM64 debug 簽署測試包，可直接側載到 Android 裝置；已通過 APK v2/v3 簽章與 16 KiB 對齊檢查，但不是 Google Play 正式簽署包。

驗證：完整 `bash tools/check.sh` **2,206 項斷言通過**，零 SCRIPT ERROR／ERROR／FAIL；另完成原生戰役的八格跑步、三語部件選單、農具生產與近域採集檢查。iOS Xcode 專案已產生，真機與 App Store 簽署仍待連接裝置及 Apple 開發者權限。
