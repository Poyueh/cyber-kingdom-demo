# Cyber Kingdom v0.0.9 — 黑鋼騎士接入

本次更新 H5 瀏覽器版，延續 v0.0.8 的操作與疲勞規則。

- 新黑鋼騎士正式接入主戰役：持劍、空手、待機、跑步、衝刺、疲勞慢走、拔劍、攻擊、受擊、死亡與騎乘共用同一套角色身份。
- 跑步採固定原生像素圖集，與美術預覽同源；八格交替步態維持腳底對齊，衝刺以較快播放節奏呈現。
- 徒手狀態不再顯示劍；龍晶點火、取得劍後才恢復持劍造型。
- 三段攻擊與移動攻擊沿用既有戰鬥規則，套用黑鋼騎士的斬擊姿勢；不改傷害、體力或存檔規則。
- 拔劍、喘息、受擊及死亡畫面不再跳回舊騎士圖素；騎乘保留原有坐騎動作並銜接黑鋼騎士外觀。
- 新增可重建的角色外觀資源，後續可單獨替換某一狀態，不必修改核心玩法。
