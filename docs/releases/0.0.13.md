# Cyber Kingdom v0.0.13 — v002 音效與音樂

本版整合原倉庫 `develop` 的 v002 音效更新，同時保留 v0.0.12 的部件工坊、居民工作範圍與施工防線規則。

- 全套戰役音效改用 v002 生成素材，包含戰鬥、建造、龍晶與互動回饋。
- 加入依探索、營地、夜晚守備、夜襲、巨龍及勝敗轉換的音樂。
- 環境音依地區與日夜淡入淡出；居民工作、騎乘、龍翼與封印加入循環聲。
- 主選單和訓練場也有聲音；暫停時音樂會降低並套用濾波，喇叭靜音狀態會保存。
- 玩家指南、農具工坊、部件自動裝配與 8 顆龍晶換裝規則沿用上一版。

平台說明：

- H5 可直接線上試聽；第一次請先點擊遊戲，讓瀏覽器啟用音訊。主選單與暫停選單可調整音量／靜音。
- H5、macOS、Windows、Android ARM64 debug APK 及待 Xcode 簽署的 iOS 專案均為測試包。
- macOS 未 notarize、Windows 未簽署；Android debug APK 不是 Google Play 正式簽署包；iOS 尚未產生可直接安裝的 IPA。
