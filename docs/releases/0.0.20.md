# v0.0.20 — 三星球遠征

- 保留現有微光林地，新增銹沙盆地與鏡霜海岸，包含各自的遠景、地表物件、資源分布與日夜壓力。
- 新增沙龍地裂與雙首冰龍雙段吐息；每張仍須封印雙門、擊敗巨龍並清除殘敵。
- 擊敗巨龍後領取龍核，20 龍晶與工匠建造火箭，從星圖選擇目的地。
- 落地留下殘骸，12 龍晶重建可再次出發或回訪；城鎮、居民、採集與日数分開保存。
- 騎士帶著現有晶袋、劍、部件與冷卻旅行，收齊三顆龍核通關。
- 更新繁中／簡中／英文星图、鬼魂指引、Help 與原生實錄。舊感受式紀錄可續玩。

火箭完成後，在旁按 E 或手機下滑開啟星圖。七星球及集結旗幟尚未完整實作。

提供 H5、macOS、Windows、Android debug APK 與待簽署 iOS Xcode 專案。macOS 為 ad-hoc，Windows 未簽署；Windows／手機本次未真機驗收。
