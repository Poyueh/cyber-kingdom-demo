# v0.0.51 原生動作驗收

使用者否定v50的輕飄姿態與卡頓。本輪重畫扎實直腰護甲，四套走跑由四格補到八格；每格停留減半但雙步頻率不變。正常速度的起停實錄已放進三語指南，連斬也替換為本版實錄。

60Hz實際角色呈現取樣：舊版持劍／徒手步行最長9tick不換圖、快跑7tick，四項均未達本輪上限；新版分別5／4tick，四項通過。這只檢查停格頻率，不是動畫美感的量化分數。原生交接17項、步態12項、全身呈現161項通過。

transition-capture.gd與action-capture.gd使用實際輸入、正式圖集，在無存檔原生場景錄製；proportion-board.gd同倍率檢查待機／走跑。沒有新增任務或改動玩法、存檔。原稿與完整提示見art/concepts/hero-v009。

本機正常速度播放確認了較穩定的軀幹、前傾跑步與中間換腳姿勢；使用者是否喜歡新版仍待實際回饋，不把通過程式檢查寫成已獲認可。
