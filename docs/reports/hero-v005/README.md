# v0.0.47 騎士原生畫面驗收

`before-lantern.png`／`before-module.png` 是相同原生主場景的問題重現：青色面罩和紫色方塊固定疊在人物上，肩部部件過大。`hero-night.png`／`hero-module.png` 為更新後同一鏡頭，夜間照明保留。

`motion/` 的短片直接由 Godot 畫面編碼，包含徒手移動、持劍移動、快跑、原地連斬、踏斬、拔劍、疲勞與左右騎乘。前七段使用實際輸入與遊戲時間；騎乘片段以主場景人物呈現器播放左右步態，用於姿勢檢查，不代表解鎖流程錄影。

`presentation-check.gd` 另在主場景檢查左右、徒手／持劍、站立、移動、受擊、倒地、休息、騎乘與三段攻擊；同時只能顯示一個完整身體，零遊戲時間維持畫格，圖格不可越界。完整檢查與成品 PCK 結果在版本發行報告記錄。

角色原稿由內建 image_gen 產生；完整提示、參考和原始PNG在 `art/concepts/hero-v005/`。這些圖片是實際引擎渲染，不是效果示意圖。
