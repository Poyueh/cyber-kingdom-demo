## 已驗證

- TDD 先重現原版每個遺跡雙寶箱、無商人補給；加入規則後再驗證。40 個種子驗證上限、離營火距離、箱間距離、同種子重建一致。
- 一次性六晶必須以有向上速度／吸收延遲的六顆掉落物出現；不能直接增加錢包。付費一晶後才出遊，當日不交貨，次日返回、騎士靠近才交貨。

- 核心 2,397 項斷言零失敗。三語目錄與玩家指南檢查通過。最終完整 `tools/check.sh` 通過，無 SCRIPT ERROR／ERROR，包含語系、架構、匯入、輸入、存檔與主場景回歸。
