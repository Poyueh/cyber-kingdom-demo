# 騎士身形一致性驗收 v0.0.49

before.png為v48的正式像素圖集、after.png為v49同倍率對照，依序是待機、步行與快跑。走跑原稿的頭盔、胸腰及腿甲體積偏大，遊戲節點沒有橫向縮放；這是素材比例落差。重繪後仍以相同身高與單一等比例整理，不在遊戲拉伸身體。

motion/內持劍與徒手起停影片由transition-capture.gd透過實際方向輸入錄下：站立→步行→停步→快跑→停步，各135格、4.5秒。同一三倍遊戲鏡頭，人物使用正式圖集，沒有補畫／插幀；本工具禁止存檔，為觀察身形隱藏HUD及初期引導。

transition-evidence.json記錄位置、速度及實際圖格來源。既有步態12項、完整人物呈現161項通過。視覺修正以等比例畫面與連續播放確認，不新增只核對常數的測試。完整回歸與發行結果另記於release-0.0.49。
