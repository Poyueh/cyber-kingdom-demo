# 前導音訊驗證

TDD 第一輪先在原生場景重現兩項失敗：主題曲在前導期间播放、實際存在兩套音樂。修正交接後，第二輪重現五項偏好失敗：前導音樂／音效／環境音忽略儲存音量，且靜音時仍在播放。修正後原生場景 16 項通過，包含 Escape、自然完播及偏好檔位元組保留。

發行套件 v0.0.25 的九次實際關卡建立／釋放量測，熱身後資源數固定 685、節點固定 2、孤立節點 0；第 1 至第 8 次静態記憶體增加 5,660 bytes。量測器每次保留一份樣本字典，這個數字包含量測本身的配置，不能宣稱遊戲完全沒有記憶體問題。前導只播放一次；後續循環使用已看過前導的主選單與短暫點火關卡。

直接 quit 的最小音樂播放器可重現退出資源警告；停止、釋放並等 0.1 秒後退出沒有警告。一次實際 macOS 視窗關閉沒有重現。這些診斷沒有證明手機長時間穩定性，本版也未修改引擎或強制退出流程。

本版音訊偏好由 bootstrap 讀取，數值傳給獨立演出；沒有新增 domain/application 依賴，沒有改存檔或玩法。查看 [設計](../../design/prologue-audio-handoff.md)。
