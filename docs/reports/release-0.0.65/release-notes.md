手機試玩回饋五項：營地拉開、部件工坊、獵人狩獵、全螢幕按鈕、手機網頁不再那麼燙。

- 營地更寬敞：左右城牆往外移，營地裡每棟建築、塔、引魂壇和樹都有自己的空間，不再擠在一起。
- 部件工坊在找到第一個部件之前不會出現，避免一開始就有一棟用不到的建築。
- 獵人會狩獵了：沒派去守城的獵人，第一夜之後的白天會到城牆外的狩獵範圍打獵，天黑前回到弓架；也修正了獵物被歸到錯誤區域、永遠打不到的問題。
- 全螢幕按鈕：開始選單和暫停選單都有，電腦與手機都能用（iPhone 的 Safari 不支援網頁全螢幕，可以「加入主畫面」後全螢幕開啟）。
- 手機網頁效能：畫面每秒 30 幀、遊戲更新每秒 30 次、畫面解析度上限 2 倍，電腦網頁 60 幀；網頁音樂改成邊播邊解。實測遊戲中的運算量約減半，記憶體也大幅下降，應該更不容易發燙或玩到一半重整。
- 規則與存檔格式（快照 v22）不變，舊存檔保留原本的營地佈局；企劃規格修訂 52。

附件分別提供 Main／Demo 的 macOS、Windows、Web、Android debug APK、iOS Xcode 專案及玩家指南。macOS 沿用既有簽章方式，Windows 未簽署；iOS 為匯出專案，需在 Xcode 簽署與真機安裝。
