一進場就在營火旁，鬼魂直接告訴你下一步；主遊戲也能在網頁上試玩。

- 開局：新旅程改在營火左側幾步出生（原本要從約 1050 像素外的荒地走過來），第一個畫面就看得到營火與流浪者。
- 鬼魂：每換一個任務，0.3 秒內說出要做什麼並顯示 4 秒，走動中也會說；離目標遠時說「跟我來。」加上任務內容，抵達目標立刻提示，停住 6 秒會再提醒（原本移動中不說話、靠近後等 2 秒、停住 14 秒才提醒）。
- 網頁版：試玩站根目錄是森林 Demo，新增 `main/` 路徑的主遊戲網頁版；兩版存檔分開。
- Demo 分享介紹改為完整森林冒險的描述。
- 規則、經濟與存檔格式（快照 v22）不變；企劃規格修訂 48，繁中／簡中／英文指南同步。

附件分別提供 Main／Demo 的 macOS、Windows、Web、Android debug APK、iOS Xcode 專案及玩家指南。macOS 沿用既有簽章方式，Windows 未簽署；iOS 為匯出專案，需在 Xcode 簽署與真機安裝。

匯出成功不等於真機驗收：Windows／手機真機手感與新玩家理解度仍待試玩。
