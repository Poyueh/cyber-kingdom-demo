## v0.0.15：荒野探索與封印遺跡

- 新旅程加入兩座部件遺跡：讀取古龍符序、沿路啟動符石；或在 12 秒內完成疾光中繼。E／手機下滑操作，失敗免費重試，解開後領取部件。
- 森林、晶谷與遺跡加入地標和尋寶符光；暫停選單新增探索圖，以地形剪影和節點顯示已探索區與未領取獎勵。
- 寶箱變成稀缺資源：最多三個，遠離營火且拉開間距。
- 空袋時商人走近提供六晶；之後付一晶讓他出遊，隔天回營火附近，靠近再取得六晶。
- 改善存讀 CPU 耗時，保存遺跡解鎖進度和中繼期限，修正倒數結束同時死亡造成紀錄無法讀回的問題。
- 更新繁中／簡中／英文操作提示與完整圖文指南，遊戲內 H5 書本入口同步新版。

**請選「新遊戲」體驗新內容；舊紀錄保留原本經濟與部件直接拾取規則。**

七星球、集結、火箭及完整十四謎題尚未實作，本版只有兩座部件遺跡。
