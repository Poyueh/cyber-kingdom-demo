# 情境補給指引驗證

開局巡查使用種子 7、真實方向鍵／E 及正式場景；未增加龍晶或建物。自動操作約 6.5 秒點火、15.7 秒成為工匠、23.8 秒委託採集，27.8 秒引導退場，60 秒附近收到採集收入。操作腳本每半秒點 E，在招募過程曾多丟兩晶，後由居民保管／返還；因此此記錄不是最佳路線或真人速度證據。最初沙盒執行有系統字型／日誌寫入權限錯誤，只作問題定位，不列為通過的畫面驗收。

已確認的問題由核心測試獨立重現：真實採集後工匠有收入，但舊提示指向未知邊界；一晶卻持續推薦三晶弓；無晶略過免費點火；商人回程被當成立即可收貨；飛行晶體在收集保護期間被忽略。後續使用正常權限的 Godot 原生場景驗證 E、下滑、付最後一晶召回、走近居民收貨，以及三語／安全區／暫停／期限。

`tests/test_supply_guidance_scene.gd` 中的工人持晶、已領商人首次贈禮等是明確的視覺測試配置，截圖不是宣稱正常開局通關。三語排版實際發現英文與日出天數重疊，修正後重新拍攝。

沒有調整收益、怪物難度、鬼魂停留時間、召回費用或存檔形狀。核心保存／還原及隨機狀態一致性測試涵蓋反覆查詢；正式發行另驗證真正打包內容。
