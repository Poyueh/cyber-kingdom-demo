# v0.0.77 — 流浪者站在空地

流浪者改在沒有樹的空地等待與徘徊，不再站在樹下被樹冠遮住。開局、黎明新來的流浪者，以及被打回流浪者的居民，都會選最近的空地，也不會夾在兩棵樹中間；徘徊不會走進樹下。新旅程的森林在外側邊緣留一片空地讓流浪者聚集，樹木往營火側排列；城牆外各有一位流浪者等待招募。

主遊戲七顆星球與森林Demo共用。舊存檔照原本的地圖讀取；附近有空地時，站在樹下的人會自己走過去，舊地圖密林裡沒有空地的地方則維持原處。存檔格式（快照v24）不變。三語指南及企劃（修訂84）同步。

兩版各提供macOS、Windows、Web、Android debug APK及待簽署iOS Xcode專案。macOS為既有臨時簽署；本輪未完成手機真機或Windows實玩驗收。
