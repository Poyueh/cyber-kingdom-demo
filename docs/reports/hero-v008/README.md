# 騎士 v008 畫面驗收

原生 action-capture.gd 透過實際輸入重現徒手走跑、拔劍、持劍走跑、原地／移動三段連斬與疲勞；不讀寫玩家存檔。proportion-board.gd 以相同比例並列待機／走路／跑步。圖片與動畫檢查完成後記錄本次結果。

新版走跑採四個清楚的左右換腳關鍵姿勢，步行7fps、快跑9fps、疲勞4fps；不是16格細分循環。已降低步行過高抬膝，快跑保留前傾與騰空。角色共同入口與攻擊時間不變。

交接檢查修正前17處失敗，統一待機後17項通過；步態12項、原生左右持劍／徒手／騎乘呈現161項通過。正常速度起停及三段攻擊實錄用於三語指南的gait.webp與combo.webp。比例對照、拔劍、受擊與攻擊畫面附於本目錄。這些檢查不代表美術觀感已定案，保留使用者後續回饋。
