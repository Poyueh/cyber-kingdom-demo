鬼魂重新設計為陪玩家探索的夥伴：會在前方帶路、回頭等待，靠近目標時指示，工作、收晶與夜襲都有不同反應。兜帽、眨眼、龍晶胸扣和雙尾披風使用一致的像素造型。

引導以動作為主：移動時收起短句，首次靠近或停滯時才短暫提醒；大型圓徽章改成手邊小圖示，並避開角色、操作按鈕和互動資訊。

- Main：完整七星旅程，兩夜引導後原地繼續。
- Demo：森林兩夜，實體排除其餘六星，獨立存檔與應用名稱。
- 兩版同步鬼魂更新；既有規則、資源、付晶召回與快照 v22 不變。
- 企劃規格修訂 44，繁中／簡中／英文玩家指南同步。

附件分別提供 Main／Demo 的 macOS、Windows、Web、Android debug APK、iOS Xcode 專案及玩家指南。macOS 沿用既有簽章方式，Windows 未簽署；iOS 為匯出專案，需在 Xcode 簽署與真機安裝。

已通過完整回歸、原生動作與兩版成品互動驗收。Windows／手機真機手感及新玩家理解度仍待試玩，匯出成功不等於真機驗收。
