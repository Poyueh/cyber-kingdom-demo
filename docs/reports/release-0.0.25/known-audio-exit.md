# 自動退出音效資源診斷

v0.0.25 與實際已發行 v0.0.24 的 macOS 執行檔，使用 `--verbose --quit-after 1200 -- --no-campaign-save` 在前導播放中退出，皆記錄 22 個 ObjectDB／6 項資源仍被引用，列出的資源為音樂、環境音與腳步聲的播放物件。程式退出碼為 0，但不將它記為無錯誤退出。

另外一次 240 幀退出沒有警告，因此不是每次結束都重現。正式 PCK 的引導、存檔與三語測試在停止聲音、釋放場景並等待幀後沒有錯誤；不能用這項結果掩蓋直接退出的診斷。

此證據只定位到退出階段的音效資源引用，尚未證明根因屬於引擎或專案，也沒有證明長時間遊玩會累積記憶體。正常關閉視窗、重複進出場景與長時間遊玩需另行量測。此問題沒有在本版修正；本版不宣稱完成記憶體優化。詳細日誌的 SHA-256 記於 verification.json。
