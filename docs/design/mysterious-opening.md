# 神祕探索與行動前導

v0.0.40 在 v0.0.34「七個世界、古龍遺跡、未知旅程」方向上加入實際建造與防守。當次使用者要求前導呈現戰鬥、建造與具有威脅的巨龍攻擊，取代舊版只守望、不攻擊的龍。

目前演出長 28 秒，先步行點火、工匠築牆、騎士迎戰，再由巨龍吐息破壞防線；最後透過六個後續世界的地景與片名銜接主選單。七個光點是世界意象，不透露解鎖條件。五句三語字幕、不加配音或任務。

場景使用既有遊戲演員、施工、命中、龍息與音效；星球掠影只有呈現，不建立六套模擬。詳細鏡頭、落地與介面規格見 [落地與行動前導](grounded-cinematic-interface.md)。時間、站位與導演數值由 `data/opening_direction.tres` 編輯。

## 生命週期底線

- 可隨時按跳過、Enter／Esc，主選單可重看；跳過輸入不能穿透成建立旅程。
- 獨立 World2D／舞台與正式旅程分離，完成或跳過即釋放。
- 主選單配樂暫停後交給舞台，结束再恢復；沿用玩家音量與靜音，不改寫偏好。
- 觀看、重播、取消不建立旅程；新遊戲仍須在節奏頁確認才建立。
- 所有粒子、影子與演出狀態都有固定數量或生命期，快照維持 v20。

需驗證完整自然結束、連續重播、跳過與重入、三語版面、音樂無重疊及存檔隔離；必須播放實際原生畫面。測試不代表已證明玩家會更想玩。
