# 七星球神祕開場與主選單（v0.0.34）

使用者選定「神祕探索：七顆星球與古龍遺跡，強調未知旅程」。開場要讓人想踏出第一步，不預先講完故事或展示解法。

演出約二十秒：龍晶回聲與騎士穿過森林 → 六個後續世界的遺跡短景依序淡換 → 古龍守望與標題出現 → 淡入星環廢墟中的主選單。世界圖像直接用現有遊戲素材；七枚亮點是演出意象，不是航線解鎖資訊。四句字幕支援繁中、簡中與英文，無新旁白。

主選單以星環、騎士、營火、火星與星光承接未知旅程。暖金色「開始旅程」為主操作，選紀錄、圖文指南（Web）與重看開場為次操作。保留原有節奏選擇與所有存檔安全行為。開始旅程到確認節奏前不建立存檔。鍵盤焦點清楚可見。

演出可隨時跳過（按鈕／Enter／Esc），重播與自然結束均釋放隔離舞台，標題配樂先暫停再交接；音量與靜音不被改寫。重複要求重播只保留一個舞台。自然結束先淡出，選單淡入；跳過直接交回選單，不額外等待。

時長、鏡頭起點與淡入淡出集中在 data/opening_direction.tres。新畫面只讀呈現資料，沒有新存檔欄位，快照仍 v19。演出的舞台與玩家世界隔離；星球掠影是純呈現，不啟動六個世界的模擬。主選單只繪製固定數量的素材與粒子。

驗證重點：實際播放、自然結束、兩次重播、跳過輸入不誤開旅程、音訊不重疊、靜音、無玩家存檔寫入、三語主選單與節奏／紀錄頁、完整回歸、正式匯出包與線上指南一致。舊「夜間怪群戰鬥」場景預期刻意改為神祕世界掠影，並非略過失敗。

不能從自動檢查推論玩家一定更想玩；真人試玩觀察應是是否看完、是否想點開始，以及是否能說出期待探索什麼。
