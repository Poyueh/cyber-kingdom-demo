# 落地場景、介面與行動前導（v0.0.40）

驗收情境：玩家觀看一段真正施工與交戰的開場，看見巨龍從畫面右側逼近、蓄力、吐息摧毀剛完成的防線，再由七星球遺跡進入主選單。進入遊戲後，環境底部貼合路面，主玩法保持少量圖示。

## 場景落地

沙漠與冰霜遺跡圖片有 10／8 像素底部透明留白；星球背景樹木與灌木也有留白。原本直接以圖片矩形底部對齊地面，與森林已有的 GroundedArt.anchor 不一致。星球背景、主要遺跡、舊 frontier props、前導地標與主選單演員統一採可見底部定位；保留視差、原圖像素與物理地面。星球植被深入路面 2 像素避免細小縫隙。空中的星環碎片屬天空景物，不作為可步行地面。

## 介面

以深色石墨面板、霧金邊線、龍晶青色選取與清晰焦點統一主選單、語言、節奏選擇、暫停及部件等共用控制。觸控攻擊／選單以透明圓形底盤取代黑色方塊，按壓有不同亮度；104 像素攻擊按鈕、58 像素觸控半徑與手勢排除區不縮小。

主選單右側在較低視窗可捲動，英文節奏說明可完整取得。主玩法不增加常駐文字面板、血量或任務；晶袋仍只在收支後短暫顯示。

## 前導與巨龍

- 0–2.8 秒：林地步行接近最後營火。
- 2.8–8 秒：拔劍點火、聚落顯現，工匠完成城牆，沿用實際施工進度與動畫。
- 8–13 秒：三隻噬晶獸壓近；騎士透過原本劍擊判定造成傷害，沿用命中停頓、斬擊、碎晶與音效。
- 13–21 秒：巨龍從右側接近，陰影先壓暗天空；導演在較遠位置鎖定防線、蓄力後交由真實龍息流程結算，摧毀城牆，留下震動、塵屑與餘燼。
- 21–28 秒：六個後續星球遺跡掠影與片名，銜接主選單。另有開始 0.7 秒淡入。

森林龍吐息起點現在跟隨四個完整攻擊姿勢的嘴部位置與怪物當前位置；原先固定在釋放當下的座標，龍繼續前進後火焰會與嘴部脫離。四個嘴部錨點保存在 EnemyAppearance 資源，不拆解或拉伸身體。普通遊戲也受益於此純視覺修正，傷害、警告、範圍與回復時間不變。

前導是獨立 World2D 的可丟棄舞台；不讀寫玩家旅程／音量設定，不新增核心存檔欄位。舞台的敵人、站位與破牆攻擊力不改正式旅程的平衡。破壞的城牆改為低矮殘基與散落木石，清楚表示通道已開；維修時顯示原施工架，正式遊戲同樣適用。前導不顯示遊玩用的「龍核暴露」教學牌。所有新字幕同步繁中、簡中、英文。跳過、Enter／Esc、重播、音樂交接與靜音維持。
