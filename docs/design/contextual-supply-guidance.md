# 把收入接回探索與建造

v0.0.24 的開局輸入巡查可完成點火、招工與採集。唯讀提示存在落差：資金查詢只找商人、地面晶體和寶箱，漏掉工匠隨身收入；有一晶就會建議三晶器具，付不滿又退回；無晶時甚至略過免費的首次拔劍點火。這些是提示與真正規則不一致，並非需要增加收益。

## 取捨

增加常駐任務清單會遮住世界，也違背既有感受式介面。增加免費補給會掩蓋問題。本輪選擇修正既有鬼魂的情境建議：已知且安全的立即收入 → 已付款的採集／商旅 → 未知邊界探索。仍只在開局期限或付費召回期間出現，不增加強制教學或額外晶體。

## 可見結果

- 錢不夠付完下一筆工程時，先提示向持晶居民收貨，或取附近已知晶體／寶箱／可交貨商人。已填入格數計入剩餘費用，後期火箭建造也使用同一條判斷。
- 已委託的採集仍在進行時，說明等工匠完成後靠近收取；商旅回程指向營火交貨點，隔日到貨則明說明早。
- 未點亮營火且無晶，仍可先免費拔劍點火。舊規則中需付費的營火繼續按真實價格判斷。
- 工匠、商旅、守夜和封印各有正確的等待／操作說明；不要把一切等待都寫成領取器具。
- 不變更收益、地圖、隨機數、戰鬥、存檔形狀或鬼魂期限。只有已知收入可定位；受威脅居民不能當安全收貨來源。

## 驗證

TDD 先以真的採集完成／居民持晶流程重現錯誤，再覆蓋不足付款、已填格、免費點火、回程商人與舊存檔唯讀一致性。Godot 原生畫面檢查三語文字、手機提示、靠近收貨與退款；這些不等於真人理解度或留存率證明。
