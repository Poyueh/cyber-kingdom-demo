# v0.0.44 動物、扎地與介面

動物的來回位置原本已有核心模擬，但畫面一直使用同向靜圖。現在 wildlife_motion 讀取實際位移，記住面向與行走距離，使用完整原圖翻面及一像素步伐起伏，腳下附淡接觸影。暫停維持姿勢；轉場、讀檔與時間倒退重設純呈現記憶，不加入快照欄位，也不複製核心的移動公式。這不是新增多幀腿部動畫。

透明邊界貼齊路面仍會因草緣與圖像底部的稀疏像素顯得微浮。grounded_art 統一在可見底邊校正後下埋 4 世界像素，含樹、石、遺跡、馬廄、火箭分幀與沿途物件。光罩沿用同一錨點；不改地形、碰撞或互動座標。動物獨立排除景物下埋。

介面共用深石墨底、青灰選項、暖金主操作、立體邊緣與細角框。裝飾依面板外框繪製、不穿越標題且不攔截觸控。標題 22、操作 18、內文 16、輔助 14；品牌大標保持 52。英文節奏選項移除擁擠圖示，保留可閱讀文字和選取色。主選單、暫停、探索圖、星圖與部件都使用共用樣式。低視窗可捲動；保留主玩法圖示優先。

數值集中 data/scene_finish.tres 的 Resource 預設欄位，玩法與存檔 v20 不變。原生畫面、三語排版、七地巡覽與完整回歸是驗收依據。Windows／手機仍需真機驗收。
