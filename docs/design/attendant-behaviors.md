# 駐點人物的無文字互動

六位原有駐點人物繼續使用完整身體圖格與固定像素比例。工作由不同的停頓、重複與收手順序構成：守望者提燈巡看；機械師檢查、敲修；育種師拈種、篩籃；獵務官整理箭簇；晶工校準晶片；軍需官檢查盾具。微小職業特效跟隨出手時機，不產生物品或居民。

接近後稍作反應，再短暫轉向玩家，收手後繼續工作。進出範圍分開且有招呼間隔，久站不重播，穿過人物不急速翻面。現有投入動作有短回應，真正完成器具、升級／充能或換裝才有完整服務姿勢。既有費用與按鍵不變，無新對話、任務或額外獎勵。

活敵靠近時中斷工作並警戒，安全一段時間才恢復。夜晚無敵仍工作。所有記憶最多六位、只留於呈現層，跟隨模擬時間暫停；換星／讀檔重新取樣，不重播存檔裡的舊付款。開場演出不觸發靠近／服務。

驗收：實際場景接近六站、穿越人物與反覆進出邊界；投入兩顆龍晶製錘；暫停；近敵警戒；保存還原。擷取原生圖像並檢查工作動畫。畫面行為使用場景驗證，不另造核心規則或動畫單元測試。
