# 七星部件探索（v0.0.23）

此輪把每顆星球的探索成果連到不同玩法。現有兩種重複部件，會讓後六顆星球失去新鮮感；只增加貨幣會加速失衡，只加裝飾無法改變決策。因此先實作八件互斥的主動部件，不增加貨幣種類或常駐 HUD。

新旅程：森林保留雷弧／雷槍；沙地藏磁爪、冰岸藏冷凝針、沼澤藏牽引線圈、熔谷藏工匠脈衝、雷城藏指揮透鏡、墓環藏電容。後六地各一座部件遺跡，入口仍是既有免費符石機關；本輪不宣稱十四種謎題已完成。舊旅程保留兩件配置。

初次拾取免費裝上、永久列入本趟旅程收藏；營火旁改造所八晶换回已發現的任一件。只有一個裝備槽，共用冷卻，换裝／換星／讀檔不能洗冷卻。收藏櫃呈現三個里程碑（首件、四件、全八件），只做紀念與目標，不額外給資源。未取得的部件給星球與用途線索，不揭露座標或解答。

| 部件 | 用途 | 初值 |
|---|---|---|
| 雷弧／雷槍 | 近身清群／前方打擊 | 保留既有數值，本輪不夾帶調整 |
| 磁爪 | 救回地面龍晶 | 15 體力／16 秒；200 距離內最多 5 晶，尊重滿袋、投晶保護與居民／敵人持有權 |
| 冷凝針 | 延緩攻城 | 25／16 秒；前方 180 內最多 3 敵，12 傷害；普通敵移速 −35% 四秒，巨龍僅 −10% 兩秒，不改攻擊預警 |
| 牽引線圈 | 整理怪群 | 30／18 秒；前方 160 內最多 4 敵，10 傷害；普通敵拉向落點最多 45，守門者／巨龍不位移，不穿牆 |
| 工匠脈衝 | 保護建設投資 | 25／24 秒；200 內最近兩工匠四秒施工 +50%；只加速已付費的牆／塔／拓荒站／火箭，不加速採集、不增加產量、不能令未完工設施生效 |
| 指揮透鏡 | 帶兵守城 | 20／14 秒；220 內最近三弓兵下一箭 +8，四秒到期，不強制射擊、不疊加 |
| 電容 | 行動續航 | 0／30 秒；低於 70 體力才可啟動，三秒額外恢復 30，不解除喘息或再次衝刺條件 |

無支援對象／滿袋／滿額的支援能力不收費、不冷卻。攻擊能力打空仍支付。特效有上限與期限，輪廓／颜色／護甲掛件各自不同。新數值由 data/module_catalog.tres 組合 Resource，在 bootstrap 邊界展平成純數字；條件增幅經 StatBlock/Modifier，不增繼承層。

快照 v17 保存充能剩餘 ticks 與短效狀態。已知 v16 嚴格遷移；未知或破損資料保留而不覆寫。居民／敵人短效屬於當地世界；騎士充能與共用 CD 隨旅行換算剩餘時間。測試涵蓋實際命中、工序、晶體守恆、角色失去職業、城牆阻擋、存讀續跑、跨星與無效支援不扣費。

後續仍需實際玩家驗證：首次有意義發現的時間、是否知道下一個目標、主動换裝／使用率、玩家自發返城與再出發的理由。八件收集與銷量不畫等號；十四種謎題、更多坐騎、商店宣傳與市場測試仍待後續迭代。
