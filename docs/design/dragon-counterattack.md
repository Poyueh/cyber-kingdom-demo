# 巨龍反擊窗口（v0.0.32）

七龍已有鎖定目標、有限連段與收招，但玩家缺少清楚的反擊時機與回報。本版將既有收招轉成「整套攻勢結束 → 核心亮起 → 騎士與防線一起反擊」，不增加血量、護甲或新操作。

- 僅新旅程啟用。巨龍整套連續攻勢完成後，至少有六秒龍核曝露；既有較長收招保留。森林原有較短的吐息後冷卻延長到六秒。
- 曝露時，我方實際傷害為原本的 1.5 倍，四捨五入；劍、攻擊部件、居民與箭塔共用同一規則。指揮加成先加入，再套曝露倍率；同一刀不重複命中。
- 登場停頓、攻擊預警與兩招之間都不算曝露。平時仍可造成普通傷害，不設無敵盾；其他魔物仍可能威脅玩家。
- 核心有金色菱形、青色裂環和少量上升光點。每種龍按原圖定位並隨朝向鏡像，整個窗口持續可見。開始時短音效及三語文字顯示 1.8 秒，不新增常駐 HUD。視覺取世界時間，暫停同步凍結。

比較過只加教學文字、硬性護甲／無敵階段、另建破甲累積條。前者缺少行動回報，後兩者增加數值或等待成本；採既有收招期間的正向加成，讓保留體力、部件與帶兵有共同時機。

data/dragon_opening.tres 是新旅程數值來源，bootstrap 在建立時注入並隨原有 config 保存。domain/dragon_opening 從已保存的 windup、cooldown、target 與生存狀態推導曝露，不增加第二個計時器或 mutable 存檔欄位；傷害由 StatBlock／Modifier 計算。application 控制最後一拍的收招與短效事件，presentation 只讀取規則呈現。

快照維持 v19。舊紀錄不補新設定，保留攻擊時序、傷害和畫面；未知／缺項設定、非法數值與跨星混合規則拒絕載入。十四份真正 v0.0.31 套件建立的七地預警／收招存檔，續跑六十 ticks 與舊版完全相同。

驗收包含七龍整套連段、一次性命中、部件／弓兵／施工中塔、暫停、三語、真實鍵盤與觸控輸入、十四份新規則戰鬥中存讀接續。這證明規則與提示一致，尚不能證明真人覺得節奏更好；下一輪試玩觀察玩家是否能識別窗口、是否保留體力、是否願意帶兵出征。
