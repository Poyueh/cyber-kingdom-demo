# 八種可狩獵生物

v0.0.70 以原有鹿的細緻像素質感統一其餘七種可狩獵生物：野兔、野豬、狐狸、獾、山羊、雉雞與陸龜全部重製完整八格動作，補上毛皮、羽毛、角、甲殼與有體積的明暗。移除五色粗方塊身體與獨立矩形腿，改讀預先整理為原生一像素密度的完整動作圖集；每個物種全循環固定比例與地面錨點，依實際行進距離換格，停步／暫停保留姿勢，轉身只鏡射整張圖。鹿保留原圖與既有呈現。主遊戲、Demo與舊紀錄共用，維持八種外觀、原數量與每次狩獵2晶，不改AI、速度、分布或存檔v23。

## 造型與動作

| 物種 | 識別特徵 | 原生圖素上限高度 |
| --- | --- | --- |
| 鹿 | 原有青色晶角、棕色皮毛與細腿 | 沿用原素材與0.75顯示比例 |
| 野兔 | 長耳、白尾、棕灰毛與收放後腿 | 40px |
| 野豬 | 深色鬃毛、厚肩、獠牙與分趾蹄 | 39px |
| 狐狸 | 赤色皮毛、白胸、黑腿與白尖長尾 | 36px |
| 獾 | 黑白面紋、灰背、低身與短爪 | 30px |
| 山羊 | 後彎角、鬍鬚、淺腹與細長蹄腿 | 56px |
| 雉雞 | 青綠頭、白頸圈、銅色羽翼與長尾 | 40px |
| 陸龜 | 分節甲殼、鱗皮與短腳 | 24px |

七種新圖集位於 `art/characters/wildlife-v002`，每格96×80、四欄兩列，地面錨點(48,74)。`data/wildlife/*.tres`提供貼圖、格尺寸、格數、步幅與陰影半寬，呈現層逐格畫完整身體，不再拼接四肢。原稿與提示在 `art/concepts/wildlife-v002`，以 `tools/prepare_wildlife_art.py`作透明連通區裁切、單一固定比例最近鄰取樣與腳底對齊；原稿不放進發行包。圖集、逐格預覽及循環預覽共用同一組像素。

## 共用狩獵規則

物種由既有獵物位置的穩定索引輪替，不消耗世界亂數；讀檔、日出恢復與返訪不重新抽外觀。新旅程仍近郊左右各三隻、遠林每補給區三隻。舊無標記紀錄保留原數量與生死狀態，不為湊滿種類增加動物。每次狩獵仍獲得2晶，沒有新增物種專屬AI、逃跑速度、掉落、任務或防守負擔。

## 驗收

以Godot原生繪製器比對鹿與七種新造型、雙向逐格動作、停步及實際森林場景；沿用人口、存讀檔、日出與獵人回城測試。兩個版本的實體匯出須帶齊七張圖集，Demo仍排除其餘六星專用內容。
