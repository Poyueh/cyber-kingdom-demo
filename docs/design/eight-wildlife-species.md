# 八種可狩獵生物

v0.0.69 可狩獵生物擴為八種：鹿、野兔、野豬、狐狸、獾、山羊、雉雞、陸龜。狐狸有蓬鬆擺尾，獾有低身與白面紋，山羊有角與長腿，雉雞有長尾及雙足步態，陸龜有分節甲殼及短腳；每種有獨立像素輪廓、配色、步幅與抬腳設定。造型由既有獵物位置的穩定索引輪替，不消耗世界亂數，讀檔、日出恢復和返訪不重新抽外觀。新旅程、主遊戲、Demo與舊紀錄共用外觀；不再加密數量，仍近郊左右各三隻、遠林每補給區三隻，舊無標記紀錄保留原數量。全部是既有獵人實際可狩獵的獵物，每次仍得2晶；不新增任務、掉落種類、動物速度或防守負擔。快照仍v23。

呈現資料位於 `data/wildlife/*.tres`，鹿保留既有素材。其餘七種使用共同兩像素網格，圖案、顏色、腿位置、步幅、抬腳、身體起伏與尾巴由各自Resource提供，呈現層讀實際移動距離，不以時鐘空踩。雉雞只有左右兩腳，陸龜不彈跳，狐狸尾巴隨步態起伏。停步／暫停保留相位，轉身只鏡射同一輪廓。

八種是共用狩獵規則下的不同視覺物種，不宣稱新增物種專屬AI、逃跑速度或獎勵。排列固定但分散於實際生成的森林獵物位置；近郊六個位置不保證一次看完全部，向遠處林區探索可見其餘物種。舊的兩隻族群仍只顯示其兩個位置，不因更新強制補齊圖鑑。

驗收：Godot原生八種輪廓與雙向步態預覽、主場景近郊及遠林顯示；沿用人口／存讀檔／日出／獵人回城回歸。主遊戲與Demo的實體匯出均須帶齊新Resource，Demo仍排除其餘六星專用內容。
