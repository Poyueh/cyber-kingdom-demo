# 像素日月與天空融合（v0.0.43）

v42 的單色圓盤直接覆蓋背景，造成貼紙感；光暈又受到天空遮罩截斷。保留等比例世界座標，日月中心偏亮、邊緣帶當下地平線色，圓緣使用窄幅四階像素透明度。盤面保留有限雲色變化，不以雲遮罩切碎輪廓；月面加入固定、低對比像素斑點。

光暈在背景混色之後合成，24 階有序抖色與兩世界像素網格保留像素風格；覆蓋強度向下衰減，不用全螢幕模糊或新增粒子。太陽偏淡金／暖橙，月亮偏冷藍且較弱。前景樹木正常遮擋。

晨光使用獨立晨空與地平線色，夕照沿用晚霞色。日月在各自時段首尾 10% 漸入／漸出，星光依晨昏同步漸變。白天末端與夜晚起點、夜晚末端與白天起點各自使用相同端點色，沒有瞬間換色與圓盤跳出。

參數位於 data/daylight_style.tres：Sun Halo Strength 0.3、Moon Halo Strength 0.16、Halo Extent 4.5。Sun Radius 保持 17。無額外呈現計時器，完全讀取既有戰役時鐘；暫停、讀檔及跨星不引入額外相位。僅改畫面，日夜長度、敵潮與快照 v20 保留，新舊旅程皆套用。

原生驗證涵蓋三個畫面比例的日月輪廓、圓盤外光暈、兩個交界的實際像素連續性；另擷取實際旅程六個晨昏／日夜時點與七種背景。真人美感回饋與手機真機效能仍分開驗收。
