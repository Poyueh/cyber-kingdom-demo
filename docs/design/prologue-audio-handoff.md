# 前導與主選單音訊交接

前導播放時，主選單在背景仍執行 TitleAudio，造成主題曲與劇中配樂同時播放。前導使用獨立戰役且不讀偏好檔，原本也忽略玩家已儲存的音量和靜音。

主選單統一讀取一次已驗證的偏好，將唯讀數值傳給前導舞台；前導仍不讀寫偏好或戰役存檔。維持既有劇場混音比例：音樂為玩家音量的 55%，音效 50%，環境音沿用玩家設定。靜音覆蓋所有聲音。主選單配樂在前導期間暫停，自然播放完或跳過後恢復；暫停演出不改寫玩家的靜音選擇。

驗收使用真實主選單、前導戰役與 Escape 輸入，確認配樂不重疊、自然／跳過兩條交接、三軌音量及靜音，且偏好檔位元組未變。核心規則與存檔格式不變。

另外診斷到強制退出時的音效釋放警告：單一 AudioStreamPlayer 也能重現，停止並等待混音處理後沒有警告。一次實際桌面關窗未重現；九次關卡切換的資源／節點數穩定。這不等於完成長時間遊玩或手機記憶體驗收，也不把退出警告當成本版已修正。Godot 的 [退出通知文件](https://docs.godotengine.org/en/stable/tutorials/inputs/handling_quit_requests.html) 說明直接 quit 與正常關閉通知的差異。
