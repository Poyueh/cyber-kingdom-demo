# 雙側劍盾守軍與建築佔地（本機開發版）

2026-10-21使用者要求；尚未公開發布，兩個遊戲版別共用。

## 玩家流程

營火三級後，左右防線內側各有一座兵營。靠近按E／下滑開啟兵營面板，顯示劍盾兵總數、已指派、未指派及左右到位人數；每派一人1晶、撤回免費。劍盾兵不會上塔，只能守在選定側的牆內。原弓兵號令台仍只處理弓兵。

兩座兵營共用原來的劍盾裝備庫存，最多3組；面板用標示的3晶一次備妥一組，缺晶／滿架／不在兵營時拒絕且不扣款。這避免暫停中的零散付款被既有暫停退款流程退掉。居民會去最近的兵營領取工具並成為真正劍盾兵，不免費增加人口。

## 防線與空間

建築規則在付款前檢查佔地：固定營地設施、塔、城牆、施工、第一晶已投入的建地、救援船、車庫、引魂壇與火箭預留地都參與。已建物的原地升級可進行；不刪除或重排舊建築和地圖，重疊的新訂單拒絕付款。共用佔地檢查見application/construction_space.gd。救援船以完整船寬避開既有建築藍圖選址，保持確定性；舊船修復／候船進度保留，農地與地圖不改位。船址仍限營火右側1750–3500像素（受地圖右界限制），不因避讓而推往遠方。

兵營在目前外側完工城牆內選最近的空位，避開既有設施。最後一面牆也毀壞時，兵營保留在初始城牆遺址內的空地；沒有足夠空間時不把兵營硬畫到其他設施上。佔地幾何變化時才重找兵營位置，不由畫面重新抽位置。

劍盾兵在牆後近距離待命，擴建後跟進新完工外牆。破牆且附近已有敵人時先在缺口近戰阻擋；沒有近敵才回到現存防線。保留正面舉盾、出招前搖、背擊與龍息弱點。已指派劍盾兵與弓兵均不被號令旗抽走。

## 拾晶與保存

已集結的整隊及投入首晶、尚未付滿的集結候選名單不撿地上龍晶；既有隨身財產仍可交還騎士。一般居民原來的收晶與轉交保持。取消／退款後解除集結預留。

劍盾指派保存在既有core_loop.orders陣列，以sword_left／sword_right表示；沒有新增快照欄位，沿用v24。還原時驗證人物職業、禁止劍盾上塔、禁止同一人兼任隊伍與守軍；舊v24及歷史升級流程保留原世界與收益。存讀後繼續模擬須與不中斷一致。
