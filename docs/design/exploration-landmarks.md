# 邊境探索地標與探索圖

本輪已接入目前單張戰役地圖，不等同於七星球、火箭或解謎玩法完成。

## 玩家體驗

- 林地以枯木、倒木和機械殘件組成旅人遺跡；晶谷以岩脊、晶簇和殘件組成礦區；遺跡以斷拱與龍像形成聖所輪廓。
- 每個區域一組地標，優先依實際部件位置配置，其次寶箱，沒有獎勵則在區域中段。部件和寶箱同區時，地標與符光指向部件，不誤報別處的寶箱。
- 有未取得獎勵的地標在地面閃動青色符光；取走對應獎勵後熄滅。附近一般中大型裝飾讓出空間，沿用落地定位與薄霧漸現。
- 暫停 → 地圖圖示，開啟邊境探索圖。金色箭頭是騎士，斜線帶是未探索區；點地區或圖示可查看名稱。地圖不提供傳送。
- 僅揭露已探索區域中的未開寶箱與未取得部件，門遵守既有發現狀態；領取後下次開圖即移除。營火一直可辨認。
- 關閉地圖返回暫停選單；恢復遊戲或重開旅程自動關閉。繁中、簡中、英文一致支援。

## 維護邊界

`application/exploration_survey.gd` 提供唯讀探索資料，無 Input、Node 或存檔操作。`presentation/exploration_chart.gd` 繪圖和選取；`exploration_map.gd` 排版；bootstrap 連接暫停選單。`exploration_landmarks.gd` 只組合既有原尺寸像素素材，不產生碰撞或可付費物件。

地圖生成種子、資源數量、寶箱稀缺設定與城牆外工作範圍未變；不增加龍晶收入，不要求重開旅程。沿用存檔 v14 的發現／領取資料，沒有新增存檔欄位。

下一輪可增加少量有代價的探索事件與區域特有互動；應先確認本輪方向辨識，再擴充玩法，避免用更多寶箱取代探索內容。
