# 森林水岸與前導演出

- 步行與快跑使用相同既有八格跑姿，頻率由實際水平速度平順轉換，預設 10–16 fps；停止時保留步態相位，重新移動不固定從第一格起步。沒有重畫角色素材，保留持劍／無劍、騎乘、受擊、喘氣與攻擊分工。
- 三層背景樹採不同捲動倍率、尺寸、色調及輕微搖曳；前景另放低矮蕨類與倒木。純呈現、可視範圍內繪製；不消耗戰役亂數，也不改探索資源。交錯高度避免整排等高樹冠。
- 水岸鏡射的過渡帶約 34 世界像素，邊線以不規則波形和岸邊原色漸混，不再沿單一直線切入反射。延用一次 screen texture 讀取；沒有額外世界複製。
- 林間斜光以單一 shader 混合暖色日光／冷色月光，隨戰役時鐘同步。營火上部火舌上下與左右波動，餘燼升起；暫停時停止。
- 已建成的主要設施旁增加符合職業的店員待機身影，三頭身比例一致。只作視覺呈現，不憑空新增免費勞力；敵人接近時隱藏避難。
- 引魂壇費用一顆，開場自動引導維持原本機制。詳細規則見 spirit-summoning.md。
- 感受式旅程死亡時場景暗下，依營火熄滅／騎士死亡顯示不同兩句敘事，附曾守護的天數；2.8 秒後顯示重試控制。勝利使用黎明文字。舊戰鬥測試模式保留原有立即操作。
- 首次啟動前導長 25 秒，直接用真實場景、演員、戰鬥與巨龍分四段演出：荒野接近、拔劍點火、夜襲交戰、巨龍威脅；只保留三句氣氛字幕與可跳過按鈕，繁／簡／英同步。
- 前導是獨立 SubViewport、World2D 與會話，沒有玩家存檔或偏好寫入；自然結束／跳過都釋放整個場景。主遊戲不保留這個額外 viewport。仍需 iPhone 真機驗收 H5 長時間效能。
