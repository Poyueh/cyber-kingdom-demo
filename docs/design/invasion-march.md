# 夜襲遠程行軍（v0.0.30）

基線量測：七地、三個固定種子的第四晚，第一名敵人進入防線外 320 距離需 93.8–109.5 秒；假設進入就立刻被消滅，夜晚仍需 120.0–217.8 秒。這是省略所有交戰時間的等待下限，不代表真人過關時間。長地圖令探索有規模，但遠程步行把守城張力拖散。

新旅程普通魔物在遠離騎士、非流浪者居民、營火及已投入建設的防線／箭塔時快速行軍。接近戰區逐漸降回原速度；不依賴攝影機、不傳送、不在玩家旁增生敵人。近戰起手、攻擊頻率、血量、傷害、每日總敵數、兩門及封門規則不變。守門者與巨龍不加速。抱晶普通魔物在遠離戰區後也能快速返回原門；仍需實際走到門、不能穿牆，不增加掉落。

選擇這個方案是為了縮短空等。直接增加所有敵人的移速會改變近戰與居民撤退；天亮直接刪掉遠處敵人會讓付費防守失去意義，這兩種方式不採用。

數值為新 Resource：遠程倍率 3，戰區半徑 1000，漸變帶 500 世界單位。乘數走既有 StatBlock／Modifier；部件緩速仍生效。資料在旅程建立時保存，不動舊紀錄；只新增物件型子系統，不新增反射存檔欄位，快照保持 v19。未完整配置或未知規則版本拒絕載入。

驗收：量測前後同種子七地；實際移動、距離漸變、工人／騎士／外牆／箭塔附近原速、守門者／巨龍不變、抱晶回門／牆阻擋／晶體守恆、減速部件、存讀續跑、舊版套件紀錄、原生與觸控、三語指南及五平台發佈。這是遊玩節奏調整，不宣稱能證明心流或商業成功。

新舊實際套件對照採同種子、相同初始城牆及瞬間消滅抵達敵人的受控情境；第一接觸 93.8–109.5 → 39.3–44.5 秒，夜晚等待下限 120.0–217.8 → 60.9–94.8 秒。這不包含真人戰鬥時間，不能用來保證難度或留存。

回歸調整：既有兩個出生測試原先讀的是同幀移動後的座標，假設只能走舊速度 70；改為檢查出生事件的真實門座標及向內位移，保留出生地不變的約束，不把新速度造成的位移誤判為刷怪位置變更。舊紀錄抱晶撤退連原來不受緩速影響的 105 速度也保留；新規則撤退才套用行軍及部件緩速。
