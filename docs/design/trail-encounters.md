# 七星球路邊遭遇與聚落角色（v0.0.37）

以 v0.0.36 作者路段為基礎，每星最多兩個新節奏點：一側首段荒野有一組守護晶藏的當地異獸，另一側首段荒野有安靜發現。其餘留白不再追加互動，聖所、戰馬與龍門前庭保持原本用途。沒有新增謎題或每日重生獎勵。

方案比較：定時全圖刷怪會疊加夜襲；每段放事件又回到密集互動；採用固定預算的地形據點，位置隨已解析路段變化。遭遇具有可見徵兆、蓄力、有限追逐與明確收招。怪物留在領域內，撤離後不追進聚落，受傷不自動恢復。清除只解鎖一次性少量龍晶，另一側發現不需戰鬥。此兩處都是選做，不阻止黎明、封門、龍核或星際旅行。

v0.0.39 新旅程的森林改為單獸短撲（36 血量、1.2 秒蓄力、2.4 秒收招），先讓玩家看懂一隻怪再面對後續雙獸。既有 v0.0.37–38 森林存檔保留雙獸、0.85 秒蓄力和 1.8 秒收招；沙地單獸長突進；冰岸慢速廣掃；沼澤雙獸錯峰襲擊；熔脊大範圍重掃；雷城快速錯峰衝擊；墓環長蓄力延遲突進。每種使用既有當地異獸完整動作，速度、範圍、蓄力及收招從 Resource 解析，新旅程保存實際設定。一次最多兩隻，沒有全圖隨機刷新。

戰役新增純規則的有限遭遇進度與 tick 計時，application 負責既有戰鬥／互動接線；保存格式新增版本與舊檔遷移。舊旅程不追加遭遇。驗收包含相同種子、逃離、收招窗口、獎勵一次性、戰鬥中存讀、跨星返訪及未知／損壞檔案拒絕。

六種駐點人物有獨立頭飾、體型與職業道具。五種功能建築與拓荒站採同一暖木／黑鐵／龍晶材料家族、不同剪影。以生成完整姿勢製成共同原生網格，腳底固定、整套比例一致，移除這些人物的局部頭身拉伸；只從真實建築解鎖狀態呈現，遇敵躲避，不虛增人口或免費勞力。
