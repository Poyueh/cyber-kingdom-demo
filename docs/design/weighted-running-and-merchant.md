# 跑步承重與商人連續出遊 v0.0.52

一般移動使用跑步，衝刺加快跑姿步頻，疲勞時才慢走。補畫手腳對擺及起步、停步、轉身的完整承重姿勢，不延遲操作。修正商人同tick更新切回站姿造成閃爍，以及野外接單立刻淡出的問題；出遊終點隨接單位置決定並保存。快照升至v21，舊旅程保留原路線與進度。

一般跑姿與衝刺共用八格循環（14／22fps），疲勞使用獨立八格走姿（8fps）。hero-v010保留v009盔甲家族，重畫對擺與完整承重過渡；待機、戰鬥與拔劍仍用v009。起步0.16秒、停步0.20秒、轉身0.24秒，第一格保留上一個完整人物圖，再由支撐腳轉肩。沒有拉伸、交疊人物或輸入鎖定。攻擊／受擊／騎乘立即中斷過渡。

商人根因：60Hz更新換算30Hz tick時有同tick呼叫，原碼先清moving再提前返回，造成一幀走、一幀站。另一問題是出遊淡出使用距營火絕對距離，野外接單當下即透明。現在同tick不改狀態，接單決定至少一段完整出遊距離的終點；右側不足改往左，旅程終點保存於v21。淡出從實際出遊終點150距離開始，返回也以同終點漸現。費用一晶、交貨六晶、隔日回程規則不變。

驗收：野外交貨、回營途中接單、地圖右緣接單、同tick更新、出遊存讀續行、v20遷移、損壞／未來存檔保護。實際原生場景檢查跑步／衝刺／疲勞、持劍／徒手、轉身／暫停／戰鬥中斷；回歸不能代替玩家對自然與重量感的判斷。

## 俐落身形精修

依使用者再回饋，hero-v011 重新收窄胸腰、肩甲、護腿及靴子。十六張來源圖涵蓋持劍／徒手移動與轉身、待機、受擊、倒地、休息、拔劍、六套連斬、騎乘與空中動作。採完整姿勢、固定等比例整理，沒有執行時擠壓身形。起停與攻擊收勢仍共用正式待機圖。
