# 中景貼地與圓形日月（v0.0.42）

馬廄、戰馬遺跡與導流器原本以整張圖片底部對齊地面，透明留白造成 20、16、3 像素間隙；統一以可見底部對齊 y=430，附屬環光與指針一起移動。火箭三個施工幀各有不同底部留白，必須分幀計算；十四個路邊物件同樣以各幀可見底部對齊。既有樹木與大型地標仍沿用原本的貼地路徑。

日月原本在貼圖座標畫圓，再隨天空背景非等比例伸縮而變形。現在於世界座標使用等寬等高的 2 像素網格，半徑保留原來的垂直尺度；最高點保留完整圓面。雲色只影響天空和暈光，不能切碎日月圓面；前景樹木仍正常遮擋日月。既有 Sun Radius 資源欄位繼續控制大小。

純呈現修正，適用新舊旅程；不移動物件的互動位置、不改時間／傷害／建造規則，存檔格式維持 v20。原生 GPU 擷取驗證三種比例的日月，實際旅程巡覽七星球，並檢查馬廄、遺跡及火箭。
