# 丟晶與引魂壇

新感受式旅程：E／手機下滑在可互動建物旁沿用投入或免費互動；流浪者旁、空地或沒有可執行目標時丟出一顆實體龍晶。按住不會連續倒空背包，放開再按才丟下一顆。Q 保留為直接丟晶，不受附近建物優先權影響。

流浪者可走向附近落地的供品並撿取成為居民，不必等待騎士的兩秒吸回保護期；其他居民仍保留收集／獻晶規則。一般小怪拿晶後取消攻擊並撤回來源側地獄之門；守門者與巨龍不受賄。

開局鬼魂引導玩家點火、招募工匠、委託第一筆採集。完成後告別四秒，最後兩秒淡出；若玩家選擇自由探索，開局引導最多 150 秒。營火點亮後，右側出現引魂壇；鬼魂離開後可在此投入一顆龍晶召喚；空袋無法召回。費用讀取 Campaign Tuning → Crystal Prices → spirit，可調高並沿用逐顆填格、未滿逾時退晶。每次召回提供當前狀態的下一步提示，預設 18 秒後淡出，不因持續按住而延長。暫停凍結時間並隱藏提示，勝敗後不顯示。

`application/spirit_guidance.gd` 保存造訪狀態與 tick 期限，沿用現有首日／出征提示選擇器。呈現層負責鬼魂動作、多語文字與引魂壇；畫外設施不繪製。存檔 v9 保存引導進度，v8 舊檔依既有進度遷移，不重播已完成／過期的開局；未知版本與損壞資料繼續拒絕並保留原檔。
