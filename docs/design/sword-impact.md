# 斬擊演出 v0.0.18

- 三刀使用原本 v003 全身圖格，改變各格權重：先展示蓄力姿勢，出刀快速，回收有短暫停留。有效傷害時段與數值不變。
- 刀光為單層輪廓組合的像素弧，整數座標、不做模糊光暈／全身殘影。上挑與下劈方向不同，重劈有金色邊緣。徒手、死亡或非有效揮擊時不顯示。
- 只有騎士成功命中的事件觸發火花與停頓；前兩刀 50 ms、重劈 85 ms。打空、無敵目標或弓箭命中不觸發。多目標取最大停頓而非相加。
- 停頓只扣掉本地遊戲推進時間，輸入與選單仍可讀取；剩餘小數幀沿用 actor_body 的比例位移。不要改 Engine.time_scale。暫停保持效果，重開／讀檔清除暫存。
- Resource 提供顏色、寬度、停頓、鏡頭推力和特效上限。最多 8 組短命火花，觀察記錄只保留仍存活的效果引用，不新增存檔欄位。
- Bootstrap 組裝呈現元件，domain/application 完全不依賴畫面節點；舊練習場沿用自身回饋。
