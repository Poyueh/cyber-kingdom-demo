# 讓玩家選擇旅程節奏

v0.0.29。不同玩家喜歡的準備壓力不同，原本一律使用同一組白天長度和夜襲增援。本輪讓新旅程選「遠征、拓荒、圍城」，三種都能探索七星球、解機關、收藏部件及取得七龍核。

考慮自動依表現調難、完全和平模式與開局選節奏。採明示的開局選擇，讓玩家能預期風險；遠征預設建議，保留現有全部平衡。拓荒每地白晝加 90 秒、首夜減 1、每日增援增長減 1、每晚總上限減 20。圍城白晝減 20 秒、首夜加 2、每日增長加 1、每晚總上限加 12。森林前三種首夜分別 3／2／5，第五夜 11／6／17；各星的原有白天、首夜差異仍保留。同場上限不變，難度不增加敵人生命、傷害或移速。

較長白天也會多出居民工作時間，屬於拓荒節奏的實際經濟優勢；不是只改計時畫面。價格、掉落單次收益、起始六晶、坐騎、部件與機關不變。三種共有夜襲預警、封門取消及巨龍日數封頂規則。此為初始設計，不代表已驗證難度適合所有玩家或已提高留存。

點新遊戲先選節奏，再按開始旅程才分配新紀錄；返回不建檔。可用滑鼠、鍵盤及觸控，三語即時更新且不清除選擇。紀錄清單標示節奏；沒有標記的舊檔顯示原有旅程。遊戲中沒有額外常駐 HUD，也不提供中途改難度。

Resource 定義只在建立旅程時解出七組設定，存下實際數值。載入不重讀新版平衡表；跨星、回訪、重新挑戰沿用所選節奏。未修改 session 狀態形狀，快照仍 v19、七星封套仍 v2；新增可選數字設定 journey_style，拒絕未知 ID 及同旅程不同星混用標記。

驗證發現既有手動檢查點另存續玩漏傳 journey；已修正為保留完整星球封套。原生場景在第二星球存手動檢查點後另存，驗證目的地、森林龍核、已採集資源及七地設定仍在。既有紀錄若過去已因這個問題丟失其他星球進度，本修正不會推測重建那些資料。

核心測試涵蓋設定、生態／費用不變、波次與同場上限、七地確定性、夜襲中存讀接續、火箭往返及未知設定拒絕；原生驗證實際點選、觸控、三語、取消不建檔、讀檔／另存與重試。仍需真人試玩各節奏，觀察第 1／3／5 晚的準備時間、失敗原因及是否想再玩。
