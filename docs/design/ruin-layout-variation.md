# 新旅程的遺跡配置（v0.0.31）

目標是讓重玩仍需要觀察。實測 16 個新種子，後六地各自只有一種起始配置；換地圖後沿用上次答案即可。沿用三種可辨識的機關家族，變動現場線索與問題，而不增加貨幣、常駐 HUD 或額外操作。

- 連動燈：重新排列開關與燈的連線、選取至少兩次且最多三次操作可解的起始狀態。線路、符號與亮燈均讀取這次配置。
- 冷熱平衡：保留當地加熱／冷卻幅度與冷／熱起點特徵，改變起始與框選刻度。最短調整三至五次、必須同時用到加與減，再到菱形鎖定。
- 脈衝亮窗：從資料選取六至八秒週期，三座起始相位不同；保留原有至少一點五秒的可操作窗口、完成節點保留與暫停凍結。

比較過固定題庫與完全無限制隨機。固定題庫維護重複內容；無限制隨機可能無解或只剩盲按。採有界、可驗證的生成，所有數值由 data/ruin_variation.tres 提供。

application/journey_setup 在新旅程各地種子確定後，注入專用 RUIN_LAYOUT 亂數給 domain/ruin_layout。WORLD／LOOT／EVENT／COMBAT 的既有種子與取樣不改。生成完成即丟棄生成器，把完整配置與規則版本保存於既有封套；遊戲中不再抽籤，不需要新增持續亂數狀態。森林入門、獎勵、路線、怪物、資源與地形都保留。快照仍 v19，舊紀錄不生成新配置，未知版本和同一旅程混合版本拒絕載入。

同時修正既有場景缺口：416 號旅程冰岸的一座符石落在 1679，位於沒有 region 列的營地空地；原本 known() 與淡入值都當未知，導致看不見也不能用。現在只將左右最內區域之間的營地空地視為已知，未探索荒野與世界邊界外仍不揭露。此修正也適用舊紀錄，不更換題目。

驗收：500 種子 × 六地共 3,000 題可透過實際機關操作解開，64 種子 × 六地共 384 張真實地圖可使用一般互動拿到部件；部分進度存讀、跨星返訪、一次性領獎、原生 E／觸控和三語畫面另行檢查。16 種子的配置種類為 14／5／16／5／16／16；這是內容變化證據，不能證明玩家會覺得更有趣或更願意購買。

畫面：冷熱刻度加深底板，冰雪背景仍能辨識目標框；菱形鎖定圖示隨探索淡入。Help 使用本次原生冰岸畫面，繁中／簡中／英文同步。
