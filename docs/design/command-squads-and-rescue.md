# 號令旗、劍盾兵營與救援太空船

v0.0.72 三級營火解鎖最外側防線兩端的號令旗與右側牆內劍盾兵營。每次2晶集結現有3劍盾兵、2弓兵、1工匠，最多3隊；缺員顯示職業缺額、不扣款，不抽走已指派弓兵。隊伍跟隨騎士迎敵，工匠在附近協助已付款建築或封門；騎士進入當前城牆內55像素後全部解散，職業與隨身晶保留，下次出城需再集結。據點隨完成外牆擴張／倒塌即時轉移；沒有外牆時退回營火近防線。野外每星球一艘破船，三級後6晶修復，下一個黎明起每天1位乘客、最多囤3位，4晶招募1位真正居民，人口40封頂仍保留候船者。新功能用鬼魂帶路與短句引導，實際使用後停止，已學記憶隨存檔及跨星保留。主遊戲與Demo共用，Demo仍僅含森林。快照v24保存隊伍、修復、乘客、供給日與已使用功能，v23及更舊紀錄升級時不改地形、居民或免費補發資源。

## 集結與回城

營火三級後左右最外層城牆外130像素各有號令旗，右側最外牆內270像素有一處劍盾兵營，庫存仍共用三組，3晶一組由居民領取。旗幟頂端三格顯示目前隊數。沒有城牆時以營火左右220像素作近防線；仍有城牆的那一側沿用真實外牆。新兵營取代舊固定軍械站，不新增第二份器具庫存。原兵營看守一起移動，保留靠近招呼、付款回應與完成器具的工作動畫。

集結費2晶；需要現有3劍盾兵、2未指派弓兵、1工匠。箭塔或牆面守軍不自動調走，玩家可先免費解除指派；正在搬運或封門的工匠不被搶走。站在旗幟前28像素內優先選中旗幟，路過居民不會覆蓋互動。缺人不接受付款，顯示職業圖示與缺額；最多三隊十八人。半付龍晶沿用一秒保留與退晶規則。每隊以金、青、紫小標識辨識，士兵採劍盾外觀。

劍盾兵站在騎士前方、弓兵和工匠在後方。跟隨速度上限340世界像素／秒，不傳送。只追擊騎士320像素附近敵人；戰鬥沿用現有傷害、受擊與失業規則，戰損不憑空補兵。弓兵不分心狩獵，也不能同時指派守塔。工匠在同範圍完成已付款城牆／建築或指定龍門；附近有敵人先跟隨避險。騎士進入當前防線內55像素，所有隊伍解散，居民恢復原職業自主行動。再出城須重新付費集結。城牆倒塌或擴張直接使用現況，無需刷新場景。

## 野外救援船

每星球一艘，從既有野外區段選固定空位，保存後不重抽；不改變原地形和既有節點。未三級可看見殘骸與三級營火鎖定提示。6晶付滿立即修復，船身亮起青色能源；下一次真實日出新增一名候船居民，最多3名，不補發修好當天的免費人口。同日重複靠近／讀檔不重生；停留其他星球期間仍依原有凍結世界時間規則。

4晶招募一名，船內數量減一，產生可領工具工作的居民，不再付一次流浪者招募費。船上三窗對應實際等待人數。一般野外人口仍使用既有24人上限；船舶可補充至封閉存檔安全上限40，達限不扣款、保留候船乘客。不增加食物或其他資源。

## 首次功能引導

主流程既有第一夜教學保留。自主階段按解鎖條件與附近可操作目標，以鬼魂帶路、指向和短句提示兵營、號令旗、修復船、首次招募；農田、農具、已取得部件、馬廄、騎乘、商人、箭塔、遺跡與龍門也接入已使用記憶。提示不暫停、不搶按鍵，不新增任務列表；夜襲／近敵／巨龍戰鬥讓位給危險提示。已完成互動或已有實際使用證據的功能不再重教；玩家仍可主動召回鬼魂詢問當下流程。一般戰略目標短句與一次性功能教學分開。

已用記憶跟著騎士跨星，當地船體修復、人數和隊伍仍屬於當地世界。已有旅程只增加空白新功能狀態；既有農田、兵種等可由現況辨識，避免重新教已用功能。未來新增功能要加入這份首次使用記憶和相應三語短句。

## 驗收

至少覆蓋：三級前鎖定、缺員不扣款、部分付款、三隊上限、守塔不被抽走、跟隨與遇敵傷害、近處施工、戰損解除、回城解散、外牆擴張／倒塌、修復6晶、每日1人／最多3人、4晶招募、人口滿仍保留、JSON完整接續、舊檔升級、損壞資料拒絕、引導使用後停止及跨星保存。原生實際按鍵和畫面驗收不能由測試常數代替。
