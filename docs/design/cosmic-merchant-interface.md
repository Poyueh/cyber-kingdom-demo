# v0.0.45 宇宙星圖、商人與介面

暫停面板外的重开、換地圖、靜音三個快捷鈕全部隱藏；面板內的探索圖、星圖、存取與回起始頁功能保留。新旅程從起始頁建立，舊鍵盤 R／N 開發入口仍在。音量三滑桿全零即關閉音效架，任一調高即可恢復；讀取歷史 muted=true 時，三滑桿顯示零，避免失去靜音解除入口。偏好格式不變。

星圖保持七顆星球的分支關係及所有解鎖、返航、功績與起飛確認條件。外觀改成全景宇宙：像素星雲、細星點、七種自轉球面、背光陰影、大氣及細星環。航線使用實際前置龍核資料，開通後顯示移動光點。右側為星球詳情，低視窗可捲動；返回和起飛不隨內容捲走。星圖動畫只在可見時更新，暫停查閱不推進世界時間。

商人是一位彎月兜帽、銅面罩、青晶單眼和貨架背包的旅客。一級穿補綴赭色斗篷、背木銅晶箱；二級增加圖紋、側袋與提燈；三級穿金紋深青袍、背三窗寶塔晶櫃。營火 0／1 用第一列，2 用第二列，3 以上用第三列。外观由當地營火直接推導，升級、返航、讀檔皆同步；沒有額外收費、任務、對話或存檔欄位。

原稿由內建 imagegen 生成，來源與完整提示保留在 art/concepts/merchant-v001/，原稿不進匯出包。tools/prepare_merchant_art.py 以固定 0.21 最近鄰縮小和透明門檻處理完整姿勢，製成 96×80 原生圖格；同一腳底基線，兩格待機、六格走路。行走以實際 walk_distance 驅動，停止不踏步，不切分頭與身體。報酬、每日派遣及跨星救濟不變。

共用面板加入 24 階青黑漸層、細金框、對稱菱紋與角部刻線；裝飾不攔截點擊、不覆蓋文字，星圖改透出宇宙底。字級保留 14／16／18／22 層次。呈現數值集中 data/cosmic_interface.tres；快照仍 v20。

驗收使用原生真實場景：三語、960×450 低視窗、三級商人完整循環、七星球航行與打包後場景。Windows、手機實體裝置仍待驗收。
