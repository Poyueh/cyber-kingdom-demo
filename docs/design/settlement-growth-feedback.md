# 聚落成長與建設回顧

目前營火升級已會開放新工坊，但主要透過音效與建物更換傳達，玩家容易不知道資源換來了什麼。本輪把「付款完成 → 看見聚落成長 → 知道下一個可做的事」串起來。沒有新增經濟獎勵或強迫任務。

考慮了成就彈窗、額外貨幣獎勵及場景回饋三種方案；採短演出與可回看的印記，避免打斷操作或改變既有經濟。原有拔劍點火演出保留；二、三級營火付款完成後才觸發 6.5 秒短標題、解鎖說明及通往新工坊的龍晶光脈。附近有活敵人、或夜襲警訊正在顯示時，成長字幕讓位，光脈仍短暫出現。暫停隱藏並凍結演出。

探索地圖右上的營火圖示切到聚落頁：希望初燃（工程錘／獵弓）、聚落成形（農具）、守望之火（槍盾與堡壘改建資格）。印記讀目前星球的真實營火階段；已開放的設施仍要付費提供器具、改建防線，不能把資格當作已擁有士兵或已完工城牆。點未開放階段會說明先升營火；地圖圖示可回到原有荒野圖。

application/settlement_progress.gd 提供唯讀 UI 資料。呈現層只觀察階段變化，首筆資料作基線，因此讀檔、換星不重播；新旅程清除舊演出。最多一段短效演出、三張印記，不增加存檔欄位，格式仍為 v19。舊旅程直接使用新說明；舊獨立經濟原型不顯示錯誤的新工坊規則。
