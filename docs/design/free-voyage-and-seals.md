# 自由航行、龍門比重與失敗演出 · v0.0.46

取得首顆龍核、完成火箭並清除入侵後，可自由前往其餘六地；不必先打沙漠、沼澤或風暴。未打倒當地龍也可重建火箭換目的地。七核通關、火箭首次20晶／重建12晶保持不變。星圖採不規則散布，僅顯示所在地到選中星球的暫時航線；方向鍵按畫面方位選星。

| 星球 | 左／右門 | 設計比重 |
| --- | --- | --- |
| 微光林地 | 1／1 | 入門、建營與戰馬；封門總成本8晶。 |
| 銹沙盆地、鏡霜海岸 | 1／1 | 讓地貌與龍戰提供差異，不加封印工作量。 |
| 孢潮沼澤 | 2／1 | 西側較深的遠征，共12晶。 |
| 熔脊裂谷 | 1／2 | 東側較深的遠征，共12晶。 |
| 雷纜廢都、黯潮墓環 | 2／2 | 自選的重度遠征，共16晶。 |

新增門放在原本最外側接敵區，距同側外門830世界像素；不另加空曠長路、寶箱、謎題或常駐任務。同側由較近且未封的門出兵；封內門後出怪點退到外門，封完該側才停止該側增援。每晚總數與同場上限不因門數加倍。每門仍4晶、兩名守門者、工匠8秒，全部封完才召龍，擊敗並清理入侵後領核。抱晶怪已選定的退路保存，封門不使存檔損壞。

營火被毀：最後一擊停留0.15秒，黑幕在1.65秒完成，1.85秒開始淡入文字，2.65秒文字完整。黑幕過渡只允許騎士完成走路，戰鬥與經濟已結束；文字出現後鎖定移動。過渡期間不能用暫停／重開／换圖打斷，完成後仍可開選單回主頁。騎士死亡同樣先黑幕後文字，但死亡後不再移動。過場不新增存檔計時欄位。

器具架、操作圖示與掉落提示共用32×40像素網格的鋼鐵／皮革／黃銅外觀：長劍、工程錘、曲弓、鋤、礦鎬，以及兵營的槍盾組。保留既有角色完整姿勢與判定。

新舊旅程都適用自由導覽與視覺更新；只有新旅程配置多門，舊紀錄的門、種子、居民與資源不改寫。配置存進原有數值封套，快照仍v20、七星封裝仍v2。缺門／非法數量仍拒絕載入。
