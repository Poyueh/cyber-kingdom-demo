# 六地遺跡機關（v0.0.24）

不同星球有了不同部件，但反覆讀同一種符號順序仍缺乏探索變化。本輪增加三類可直接在關卡觀察的規則，搭配六地的不同初態、連線或脈衝。森林保留古龍符序和疾光中繼作為入門；沒有為每地另造一套操作，也沒有增加經濟產出。

| 地點 | 機關 | 玩家可見規則 |
|---|---|---|
| 銹沙盆地 | 折光連鎖 | 操作一座開關會切換相連燈；靠近時亮起受影響的線，三燈全亮開封。 |
| 孢潮沼澤 | 根脈連鎖 | 同類連動，改變起始燈态與連線關係，不能沿用沙地按法。 |
| 鏡霜海岸 | 冰脈調溫 | 加熱與冷卻調節共享刻度，把指針調到框選格後，在菱形裝置鎖定。 |
| 熔脊裂谷 | 爐心卸壓 | 從過熱開始，降壓／回溫的幅度不同，需要兩種控制配合。 |
| 雷纜廢都 | 雷纜充能 | 看旋轉指針與亮窗；在亮窗接通三座符石，各自完成會保留。 |
| 黯潮墓環 | 回聲鎖環 | 亮窗方向與間隔改變，不用全程跑秒、不要求同時啟動。 |

都靠近 E／手機下滑，免費重試。溫度到邊界再按不改值；未平衡鎖定只給短暫錯誤回饋。脈衝錯拍不清掉已充能節點，亮窗至少 1.5 秒；遊戲暫停，指針也停。解開後仍回封印處領取本地唯一部件。夜間敵人與離城風險照常，玩家可以帶著部分進度回防、再來完成。

正式互動不展示答案按序或數值 HUD。連線／形狀／刻度框／亮窗不只依賴顏色辨識；只有靠近顯示短提示，繁中、簡中與英文同步。

資料由 `ruin_mechanisms.tres` 的六個 Resource 提供，包含家族、初态、連線、上下限、調整量與時窗。核心使用具型別的機關物件與整數 tick；不額外抽取世界亂數。資料驗證會拒絕不可解連線、不可達刻度與過短亮窗。存檔 v18 增加每個新機關的兩項有界狀態；已知 v17 保留原符序／中繼，無回溯替換，未知版本保護原檔。離星後當地時間及進度依既有星球快照保存。

驗收包括真實輸入、六地旅行與領獎、存讀後繼續一致、脈衝暫停、舊版實際紀錄、32 種子 × 七地獎勵可取得。數學可解不等於玩家覺得有趣；下一轮試玩觀察玩家是否能從連線推理，以及是否因回防願意稍後再訪。
