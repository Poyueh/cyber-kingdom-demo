# 三星球遠征 · 0.0.20

本次只實作三張可玩地圖：保留原森林、新增銹沙盆地、鏡霜海岸。森林先開始，取得龍核後可選其餘兩顆；三顆龍核齊備通關。每張仍有雙門、聚落建設與獨立巨龍。沙地偏礦脈、冰岸偏遺跡，各有不同遠景、地表植被與巨龍攻擊預告。

雙門封印 → 擊敗龍並清除餘敵 → 營火旁領龍核 → 營火西側投入 20 龍晶 → 最多兩名工匠完成 30 工秒施工 → 火箭開星圖。每次落地留下殘骸，12 晶重建可回訪。未造好或場上有敵人不能啟航。

每顆星球獨立保存日數、居民、建築、採集與遺跡進度。離開的星球暫停；騎士攜帶現有龍晶、劍、部件與剩餘冷卻，商人不重送起始獎勵。旅行先驗證並儲存完整候選紀錄，再替換場景，失敗留在原星球。

原 v15 單星球紀錄可保留城鎮並升級為三星旅程。封閉的 `three_planets` v1 封套最多三個 v15 戰役快照，拒絕未知版本或任一損壞星球；不執行存檔內的腳本路徑。七星球、七套特殊機制與遠征隊不是此次全部完成的範圍。
