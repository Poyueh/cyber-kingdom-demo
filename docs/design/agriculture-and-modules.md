# 農業、探索部件與水岸

最新感受式旅程：避難所二級開放農業，同時自動搭起農具製造所。玩家付龍晶備妥鋤頭，居民自行取用；第一級即使舊存檔有鋤頭庫存，也不能提前轉職。第一級不顯示農田／農具互動，既有農夫暫停農業收益。隨機清地的農田同樣須二級，不改地圖種子與位置。犁溝、水道、灌溉管標示待開墾地。

保留騎士升級設施及三階裝備；移除主戰役暫停選單的獨立練習入口，舊測試場景只供開發回歸。主戰役不再顯示騎士治療設施，營火修復仍存在。

兩側較深的寶箱附近各有特殊部件：雷弧震盪（150 範圍、32 傷害、20 體力、6 秒）與穿甲雷槍（面向前方 300 範圍、55 傷害、25 體力、8 秒）。走近自動拾取，回騎士升級站自動入庫；按 F／齒輪開選配，只能安裝已入庫部件。每次一件，K／雙指向上滑啟動。沒有劍、力竭或體力不足不可使用；兩種共用冷卻，換裝與存讀不能跳過。

數值入口：Campaign Tuning → Special modules。純 application 元件持有 Relic／Spec 型別與 tick 冷卻；presentation 處理手勢、選配與特效。存檔 v10 明列部件庫存與冷卻，v9 及以前已知版本補空庫存；拒絕未知部件、重复庫存及不合理冷卻。

水面使用單次 screen texture 取樣，反射實際場景與角色，無額外世界 viewport 或逐幀 image readback。夜燈用一張可重用 128×128 漸層 PointLight2D，晨昏漸變。Ambience Resource 可調水位、倒影強度、鏡頭垂直位置與燈光強度。所有波紋依模擬時間，暫停不持續演進。
