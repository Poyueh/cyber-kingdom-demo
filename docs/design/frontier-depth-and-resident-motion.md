# 擴大探索與居民步伐

使用者回饋：地圖不夠探索、居民動作僵硬。這次交付增加可探索內容，以及真正交替落地的居民步伐。

## 地圖

戰役的 Campaign Tuning 新增 Exploration → Outer Regions Per Side，預設 3（每側額外三段，合計十二段），可調 0–6。原有六段與其資源位置、亂數序列保留；額外區域在外圍生成，寬 600–900，每側第一組涵蓋森林、晶脈、遺跡，順序與寬度由種子決定。遠征裂隙、地面碰撞、鏡頭邊界和龍晶邊界跟隨實際地圖。

預設種子 742601：總寬 6,800 → 11,700（約 1.72 倍），資源點 24 → 48，初始流浪者 8 → 14。人口上限仍為 24；擴圖沒有增加首晚敵人、改短白天或贈送開局龍晶。樹木、礦脈及寶箱仍有限，森林更新仍遵守保留樹木的條件。拓荒站與外牆沿原有施工規則擴展。

底層 Frontier 的預設仍不添加外圈；Campaign Tuning 在新局設定加入該參數。舊存檔設定沒有此值，因此保留原地圖、索引和存檔格式。選暫停的地圖圖示開新局才會使用擴大設定；不自動更換玩家當前地圖。

## 居民

舊四格圖集幾乎是相同跨步姿勢。此次 imagegen 生成的八格樣稿仍重複姿勢，因此只取首格造型；依使用者先前明確允許的本機處理，分離背景、保留衣裝，重作髖膝踝的交替支撐與抬腳，增加自由義肢擺臂。原圖、完整提示詞、處理工具、接觸表均保留。

六職業共用八格走路／八個待機時間格（呼吸使用少量姿勢變化），每 32 世界像素一循環，腳底不跟隨身體整張上下漂浮。停下用 0.12 秒收步；待機依居民編號錯開呼吸。獵人與守兵持器具的手保持支撐姿勢；工匠施工、搬箱、爬梯沿用原有專用動作，不丟棄工具／貨物圖像。這次未重畫所有職業的工作動畫。

ResidentMotion 位於 presentation，只記短暫步相，不修改人物規則或存檔；使用遊戲時間，暫停不繼續播放。整個新局重設呈現記憶。

## 驗證與限制

擴圖 TDD 先出現雙側沒有新增區域／資源類別的十項失敗；居民步相以最小固定姿勢介面重現距離不換步、停止不收步的兩項失敗，再實作至通過。完整檢查 1,322 項 Godot 斷言、10 個 Python 測試通過，無 SCRIPT ERROR。舊六營地的生態場景測試明確選舊地圖，新增大地圖測試另核對 24 人上限。

三張新地圖以真實 Node 物理／按鍵、正常開局資源執行：種子 1 騎士路線 885.2 秒、7 居民路線 981.4 秒、42 騎士路線 819.8 秒，皆雙封印勝利。失職次數 0／1／0；前兩局仍有牆失守，不能說不需防守。操作器有精準自動閃避，不代表真人難度適中。沒有為得到通關而贈晶、預建或傳送。

原生錄影使用刻意排列職業的視覺情境，不冒充正常資源遊玩。檢查六秒實際步行畫面、外圍地景，以及暫停前後居民區域像素相同。素材品質仍待使用者試玩認可；iPhone、Android、Windows 真機驗證不由這些測試取代。
