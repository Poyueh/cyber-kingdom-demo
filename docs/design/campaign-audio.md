# 戰役操作音效 v001

讓玩家透過聲音辨識「劍刃揮出、實際命中、已付一顆龍晶、入袋與建成」。這一版不改戰鬥數值、動畫、付款時機或存檔格式。

## 聲音與時機

16 個原創數學合成短音：三段揮劍、一般／重擊撞擊、騎士承傷、衝刺、龍晶入袋／投入、開箱、招募、聚落建成／升級、入夜、裂隙封印、勝利與敗北。沒有第三方錄音、付費套件、音樂或網路依賴。原始單聲道 PCM 為 22,050 Hz、16 bit，生成器與素材來源紀錄在 tools/generate_campaign_sounds.py、art/audio/campaign-v001/provenance.json。

揮劍聲從真實有效揮擊開始，起手蓄勢不提前出聲；三刀各自有不同短掃聲。只有真實命中特效才有撞擊，重擊另用較低的合成聲。護盾承傷也有回饋，即使生命沒降。遠處 800 世界單位以外的事件保持安靜。

目前畫面效果會存留幾幀；音效觀察器以同一份 Dictionary 的身分辨識新事件，不用內容相等誤判兩顆相同位置的龍晶。同一幀同類合併，拾取和命中再限流至至少 0.08 秒；最多六聲同時播放，拾取／付款不能打斷已滿的播放槽。其他重要聲音可替換最早開始的聲音。預設 -10 dB，音檔峰值 0.3，控制預設六聲疊加餘裕；不代表任意 Inspector 增益都不會過大。

## 暫停與靜音

暫停選單新增喇叭圖示，遊玩中隱藏。靜音立即停止現有聲音，期間仍更新觀察基準，所以恢復不會補播舊事件。切背景、重開、換圖、離場也停止舊聲；載入存檔不把既有營地當成剛建成。

靜音保留於目前戰役場景的重開／換圖，尚未保存成跨 App 啟動的偏好。系統音量仍有效。沒有增加背景音樂或音量滑桿，後續是否需要依試玩回饋決定。

## 架構與驗證

CampaignAudioCues 與 CampaignAudio 都在 presentation：前者唯讀觀察既有狀態與特效，後者管理播放槽／音量。bootstrap 接生命週期和 HUD 靜音請求；domain/application 沒有音訊依賴與新增儲存欄位。節點 CampaignAudio 的 Enabled／Volume Db 可在 Inspector 修改。

新增 22 個觀察行為斷言及 12 個觸控場景斷言；包含實際付費、三段連斬、背景停止、靜音不補播、遠處音效與新局基準。完整檢查共 1187 個 Godot 斷言及 2 個 Python 測試。

無畫面的 Dummy 音訊引擎在快速退出時會留下待清理播放資源；headless 路徑僅驗證音效請求、限流與控制，不啟動實體播放。原生模式另外經真正 AudioServer 錄下付款、連斬、命中與衝刺並量測有效訊號／零削波；這兩種證據分開記錄，無聲測試不冒充已發聲。

原生預覽放置一個測試敵人，沒有拿它當正常預算通關。音色美感、手機喇叭辨識與耳機體感仍待使用者試聽，未宣稱已獲認可。
