# 場景內的遺跡探索挑戰

使用者指出上一輪只有地標和探索圖，未真正增加關卡探索。這輪新增可在目前平地橫向場景完成的互動路徑，沒有增加寶箱數量或經濟收益。

## 古龍符序

遠方電弧部件被封印。封印上由左至右顯示三個符號，答案依當局種子排列。沿來路尋找三座機械符石，靠近按 E 或手機下滑，依符序逐一啟動。正確時亮起、錯序重置並發出紅色波紋；不扣龍晶，可免費重試。三座完成後回到封印，靠近取得並立即裝備原有部件。

## 疾光中繼

另一側穿刺部件的來路有三座中繼器。從最靠近營火的一座開始，向封印依序接通，預設 12 秒內完成。開始後，靠近中繼器會看到代表剩餘能源的收縮光環，封印處也有能源線。超時或錯序可從頭重試，完成後不必在倒數內跑到封印；解鎖永久保留。

兩種挑戰都使用原有單鍵／單手勢，不要求跳躍、消耗新材料或先取得其他部件。夜間既有敵人仍可能干擾探索，玩家可先回防、日後再來。未探索區不顯示符石；停遊戲時倒數也停止。未解開時不會自動拾取部件，寶箱仍依原規則直接開啟。

## UI 與回饋

符石依附現有原尺寸機械殘件，以符文投影和光環呈現；封印有掃光、解開有擴散光與音效。探索圖改用金色邊角、低對比網格、三類地形剪影、圓形節點和選取光環；鎖圖示代表封印遺跡。文字與 Help 同步繁中、簡中、英文。

## 資料與相容

- 新旅程的 `data/ruin_trials.tres` 決定中繼秒數、站距、互動半徑；`campaign_tuning.gd` 注入設定。
- `domain/ruin_trials.gd` 管理固定最多兩處遺跡的順序與進度，使用注入的 EVENT 亂數產生器，生成後不再抽籤；不影響既有地圖／寶箱亂數。計時採整數 tick。
- `application/ruin_interactions.gd` 對接現場互動，presentation 只繪製與觀察音效。封印解鎖不直接發放新龍晶。
- 存檔 v15 保存進度與期限，按種子和設定還原固定符序；拒絕不可能的進度、期限及未解鎖卻已領取部件的狀態。
- v14 和更舊紀錄保留直接拾取，不在舊路上追加封印。體驗本輪新玩法需建立新旅程。
- 本輪是兩座部件遺跡，尚不是七星球／十四謎題全部實作。下一輪依實際試玩調整符石辨識與時間壓力，再考慮救援、可選危險區等不同探索事件。
