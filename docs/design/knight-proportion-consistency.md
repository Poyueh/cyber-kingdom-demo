# 騎士起停身形一致性

修正騎士移動時比待機顯得矮胖的身形落差：四套持劍／徒手走跑重繪頭盔、胸腰與腿甲，統一修長比例。保留16格雙步、路程步頻與起停銜接；新舊旅程直接套用，玩法與快照v20／航行v2不變。

## 根因與基線

v48修正雙步時沿用了較粗壯的身形模板。原稿頭盔、胸腰與腿甲相對待機偏寬，兩套雖都輸出約60像素高，人體各部分比例仍不同。正常行走時呈現節點scale為(1,1)，問題在來源圖像而非執行期橫向縮放。等比例基線在docs/reports/hero-gait-v007/before.png。

## 修改範圍

以v47待機上排為角色與身形參考、v48四套16格雙步為姿勢模板，用內建imagegen重繪走跑的持劍／徒手版本。收窄腰胯、頭盔與厚重腿甲，拉回修長腿部的視覺比例。四套共用單一等比例輸出值及固定腰胯基準，不把整個圖集橫向擠扁、不逐格填滿畫布。

正式入口仍為data/hero_v005_appearance.tres，移動圖集改指向art/characters/hero-gait-v007；工具為tools/prepare_hero_gait_v007.gd及tools/build_hero_resources.py。待機、斬擊、受擊、騎乘與步態程式沿用已驗證的實作。

## 驗收情境

同一原生像素倍率對照待機、步行、快跑；在真正frontier場景以方向鍵輸入錄製站立→步行→停步→快跑→停步，持劍／徒手各一段。確認不是只在單張原稿顯瘦，起停時頭、腰、腿不突然變粗；另重跑既有12項步態與161項人物呈現回歸。體態好看與否由實際畫面及玩家回饋評估，不偽造自動美感分數。
