# 居民採集與騎士部件

正式玩法採以下規則；歷史獨立原型沿用舊搬運流程。

- 電腦 K 使用已裝部件；在營火右側改造所按 F 選配。手機在此點齒輪選配、雙指上滑使用。裝配完成後短暫顯示操作提示。部件仍需要探索取得、帶回安裝，冷卻與體力要求不變。
- 改造所距營火邏輯中心 180 世界單位，二種部件在背甲上分別顯示雷弧線圈／折疊雷槍。掛點跟著實際使用的動作影格與面向。
- 營火二級自動建立農具處，付 2 龍晶生產一把鋤頭，無職居民自動取用；庫存上限 3。農具處帶鋤頭招牌。載入後首次推進會補齊已解鎖的設施顯示，不贈送免費農具。
- 工人完成採集就將龍晶存入居民錢袋（上限 12）；超出部分掉在原地。不需回營火交貨，滿袋暫停領新採集工作；騎士靠近時照既有規則獻出龍晶。
- 工作範圍為左右有效外牆各向外延伸 Work Margin；沒有建牆時以初始預留防線計算。預設 1300 世界單位，約一個畫面，足以清出第一片區域，防止拓荒被鎖死。城牆擴張／被破壞時即時更新，已付款但超出範圍的工作暫緩，擴牆後可繼續。
- 範圍同時約束資源付款、工人領單、獵物選擇、獵人閒逛和職業居民追地面龍晶。遠處寶箱與特殊部件不受影響；封門護送與已付款施工維持原規則。
- 存檔 v13 遷移既有感受式旅程的改造所座標，保留工作進度、居民錢袋及部件。未知版本與異常座標仍拒絕載入、不覆寫。

調整入口：data/campaign.tres 的 Resident Work Territory → Work Margin；角色外觀入口 data/blacksteel_v002_appearance.tres。
