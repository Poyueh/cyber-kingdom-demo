# 居民採集與騎士部件

正式玩法採以下規則；歷史獨立原型沿用舊搬運流程。

- 電腦 K 使用已裝部件；在營火右側部件工坊按 F 選配。手機在此點齒輪選配、雙指上滑使用。新部件探索拾取當下免費裝上、替換目前部件；舊部件保留在選配清單。未取得任何部件時工坊不可互動、不顯示齒輪提示；取得後靠近工坊會亮起。每次更換另一個已取得部件須 8 顆龍晶；不足、選同一件或離開工坊皆不扣款。感受式旅程取消騎士升級購買，舊存檔既有等級保留。
- 部件仍消耗體力且共用冷卻，換裝／新拾取不重置冷卻；冷卻完成只發出一次短暫光環、齒輪與火花，跟隨騎士位置，不恢復常駐數字 HUD。存檔保留冷卻進度。
- 改造所距營火邏輯中心 180 世界單位，二種部件在背甲上分別顯示雷弧線圈／折疊雷槍。掛點跟著實際使用的動作影格與面向。
- 營火二級自動建立農具工坊，玩家在設施付 2 龍晶生產一把鋤頭，無職居民只自動取用，不自行製造；庫存上限 3。工坊有獨立鋤頭招牌與三格工具架，空架不擺假工具，生產時招牌短暫亮起。載入後首次推進會補齊已解鎖的設施顯示，不贈送免費農具。
- 工人完成採集就將龍晶存入居民錢袋（上限 12）；超出部分掉在原地。不需回營火交貨，滿袋暫停領新採集工作；騎士靠近時照既有規則獻出龍晶。
- 工作範圍為左右既有外牆各向外延伸 Work Margin；沒有建牆時以初始預留防線計算。新旅程預設 850 世界單位，標準 960 寬鏡頭、1.15 倍 zoom 約能看到 835 世界單位，因此約一個畫面。舊存檔保留儲存的設定；不隨手機螢幕長寬改變核心規則。城牆擴張／被破壞時即時更新，已付款但超出範圍的工作暫緩，擴牆後可繼續。鬼魂的採集指引同樣排除範圍外資源。
- 白天工匠與獵人可以在上述城牆外範圍工作；夜間仍沿用感受式旅程的附近敵人避難規則，本次不新增強制全體停工。
- 城牆／箭塔付滿後，建造、升級與修復期間停用戰鬥功能，工人完工才恢復。部分付款尚未開工不會停用。施工棚架、暗色建築和錘頭提示對應實際施工狀態。既有牆的拓荒邊界保留，避免升級期間把本地工單全部撤回，但怪物可以穿過施工牆；舊的攻擊起手也會重新選擇目標。
- 範圍同時約束資源付款、工人領單、獵物選擇、獵人閒逛和職業居民追地面龍晶。遠處寶箱與特殊部件不受影響；封門護送與已付款施工維持原規則。
- 存檔 v13 遷移既有感受式旅程的改造所座標，保留工作進度、居民錢袋及部件。未知版本與異常座標仍拒絕載入、不覆寫。
