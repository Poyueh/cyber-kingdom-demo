# 七星球關卡節奏（v0.0.36）

隨機地圖先有關卡順序，再變化局部。新旅程每側七段，使用獨立 LEVEL_LAYOUT 亂數流使每段寬度在作者設定的 ±50 範圍內變化，資源位置仍由 WORLD 流決定。不是把原本密集的互動全部推到更遠處；抽樣世界總寬仍約 1.6–1.7 萬單位。

每星一座主要聖所、左右各一個遺藏寶箱。森林額外保留戰馬探索；雷槍改為西側遺藏中的直接發現，八件收藏皆可取得。三座主要操作器集中於同一間聖所，間距 180 或 200，避免機關穿過營地、招募點、採集物或另一座獎勵。其餘六地保留現有可變機關家族。

用途數字：0 補給、1 靜謐荒野、2 封印聖所、3 旅人遺藏、4 龍門前庭、5 戰馬遺跡。每側最內段為補給，最外段為前庭。至少四分之一的全圖寬度為荒野／前庭；這些區段沒有採集節點、招募營地或隨機施工點。荒野保留低矮自然點綴與遠景；大型地標只在重要地點出現。非森林不再把大型聖所素材當作循環背景樹。

補給維持工匠、獵人、可再生植物與建設來源。初始可工作範圍抵達兩側第一處補給區；在補給區最外緣完成城牆，可接通下一處補給區。區內小牆仍使用原本局部距離；失去外緣牆立即退回較內防線。避免寬敞荒野使後方經濟永久不可達，也不允許跳過建設直接開發全部遠方資源。空曠段沒有新增收費橋或額外謎題。

解謎、戰馬與收藏全部選做；雙門、巨龍、七龍核主線不新增前置要求。既有敵潮會穿過這些地段，兩端前庭為接近守門者提供清楚視野。沒有新增地形傷害、跳躍要求、隱藏傳送或難度乘數。

`data/planet_levels.tres` 引用七份可編輯 Resource。`JourneySetup` 一次解析為數值設定，隨既有 v19 快照保存；讀檔不讀新 Resource 重排地形。缺少版本、未知版本、混合新舊星球配置、非法寬度與移出的機關座標都拒絕讀入。真正 v0.0.35 PCK 的七地舊檔及各自 60 ticks 接續已比對一致。

64 組種子共 448 張新圖均能用一般互動完成主要機關；同種子保持全旅程相同，其他亂數流不被佔用。種子 0 的七地採集／寶箱合計 20–29 點、重要地標 3–4 處、安靜路段 29.3–36.9%。舊生成抽樣為 60–72 點、20 組地標；這是指定種子量測，不等同真人遊玩時間或趣味提升的證明。
