# 噬晶異獸與巨龍演出 · v0.0.35

使用者選定黑色甲殼、寄生結晶、野獸輪廓與群體壓迫；全部敵人不用手持武器。參考重點是群體逼近時的清楚輪廓，採用本作原創的四肢異獸與噬晶生態。

一般噬晶獸有八姿勢步行、伏身蓄力、爪擊、受創及倒地。七地的既有守門怪各有完整圖集：森林棘背、沙地厚殼、冰岸晶鬃、沼澤孢囊、熔谷爐甲、雷城長肢、墓環空顎。守門怪的特殊性是體型、輪廓與原有精英戰力；本輪不新增七套未經驗證的傷害／異常狀態規則。出現位置、夜襲人數、抱一晶撤退與存檔規則沿用既有玩法。

巨龍保留七地不同物種，擴充完整姿勢；呈現層觀察真實 windup、攻擊事件、cooldown 與移動距離。提前播完動畫不會提前傷害，連段間預警不被視覺恢復動作遮掉，載入途中不捏造一次攻擊。吐息／元素爆發與落點同步，蓄力輪廓保留清楚可躲的落點提示。畫面特效使用短生命週期碎晶、衝擊扇面與塵浪，取消 X 字受擊記號。

素材使用內建 imagegen 生成完整姿勢後，離線統一比例製成原生像素圖集；禁止逐幀縮放配框或切肢拼動畫。原稿、提示與可重建工具入庫。動畫時鐘只跟隨模擬時間，暫停即停止；死亡後由既有 terminal feedback 推進，離場逃跑不播死亡。每敵人的暫存跟隨存活列表清理。

驗收：七地守門怪輪廓、左右面向、步行／爪擊／抱晶與死亡；七龍蓄力、連段、受擊、死亡及暂停；原生實際畫面和影片；完整檢查、五平台打包及線上套件一致性。
