# 美術像素密度

使用者要求美術圖像素密度一致。這是後續素材製作與接入的共同驗收條件，並不代表既有世界素材已全部整改。

## 製作標準

- 原生素材一格像素對應一個遊戲繪製像素；角色、居民、魔物、建築及近景物件使用同一網格。大小依世界比例決定，不把所有物件縮成相同尺寸。
- 新黑鋼騎士圖格畫布為 128 × 96，人物約 60 像素高。整段動畫共用一個等比例縮放值，保留承重時的上下起伏；不可逐格自動填滿畫布或分開拉伸手腳。
- 高解析生成原稿是設計參考。先離線裁格、最近鄰縮至原生尺寸、處理透明輪廓，再製成播放圖集。保留來源與重建工具。
- 預覽大小版必須播放相同原生圖格，只允許整數倍放大、整數落點和最近鄰取樣；不能用高解析原稿另外畫放大版。瀏覽器畫布也不能被 CSS 任意縮放。
- 像素密度不等於色數：不為了看起來更像素而隨意降低色數或改變角色姿勢。後續精修應在原生尺寸整理輪廓、色塊與孤立亮點。
- 遠景可用色彩、對比與遮蔽表現距離；不要靠不同顆粒大小掩蓋素材差異。霧、發光、水面反射的柔化與形變屬效果層，不作角色像素網格基準。

## 目前完成與剩餘落差

- 黑鋼騎士獨立預覽：新八格與前版十六格都先製成原生圖集，與既有待機／斬擊的 128 × 96 圖格一致。大小動畫及下方圖格板共用相同像素，原始高解析稿明確分開標示。
- 遊戲 `knight_visual.gd` 的現行跑步圖格也是 128 × 96，使用最近鄰取樣；新黑鋼騎士仍尚未接入，不能宣稱整套角色已替換。
- `compact_people.gd` 目前分別把居民／小怪頭與身體做不同倍率縮放；`frontier_details.gd` 部分物件也按高度縮放。最近鄰不會自動把這些差異消除。後續替換對應素材時，應直接畫成目標比例、以同一原生網格輸出，再移除局部拉伸。
- 全場景驗收仍需把最終角色、居民、怪物、牆與樹放在同一遊戲鏡頭中比較。此次只修正新角色提案的密度與預覽，不批量破壞既有遊戲素材。

重建新／前版原生圖集：在有 Pillow 的 Python 環境執行 `art/concepts/knight-redesign-v002/prepare_pixel_atlases.py`。沒有執行期影像加工。
