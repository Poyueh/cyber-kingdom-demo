# 首日圖示引導

引導是可關閉的建議，沒有自動付款、移動、探索揭露或額外資源。提示選擇從本局狀態推導。最新感受式旅程在選擇器外增加可存檔的造訪期限與引魂壇，依 [丟晶與引魂壇](spirit-summoning.md) 執行；以下保留舊版首日選擇器的規則與驗證紀錄。

## 提示順序

營火未建成時提示現場投入；已建成則招募可見且恢復的流浪者，供應工匠錘。錘架有庫存時等待居民自主領取。工匠到位後，引導探索森林並委託第一筆伐木；刻意不建議砍掉最後一棵棲地樹。已有採集委託／採木紀錄就進入獵人或守備兵準備，再準備初始兩側城牆。工程已排定不重複下單。

背包空時改找可吸收的已掉落龍晶、已探索寶箱，或實際可交易的食物；沒有已知選項才指向未探索區域邊緣，不透露裡面的寶箱或流浪者精確位置。夜晚或距日落三十秒內優先提示返回營地防守。熬過第一晚、聚落二級或勝敗後不再顯示此入門提示；暫停亦隱藏。

供應過守備武器且仍有居民等著拿時，不催買額外獵弓。提示不會改變既有最近可執行互動規則：只有建議的 key 與目前實際選定目標一致、角色落地且可付款時，才在投入鈕外顯示提示環。部分付款保留，營地真的完成才換下一項。

## 表現

中上方小面板顯示方向／操作 → 目標圖示；工匠採集以樹與錘並列。六個點表示目前教學階段，不是勝利進度條。靠近可執行目標時，投入鈕外有呼吸光環和手掌圖示。保留世界上的真實價格格與材料圖示，不再另抄價格。

本模組負責首日入門，後續由 [出征引導](expedition-guide.md) 接續；仍不保證玩家理解長按。圖示的辨識度、節奏與真人首次通關仍需測試；不能把測試通過當成人已學會操作。
