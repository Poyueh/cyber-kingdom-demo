# 可走動避難所：把選擇放回世界

使用者回饋：選單分配缺少現場操作的便利與居民自主行動的樂趣。依使用者描述的 Kingdom 操作經驗，本版改用「靠近 → 看到用途與費用 → 單鍵投入 → 角色自行行動」驗證核心循環。

## 本輪可玩路徑

投放補給 → 流浪者走去撿取並成為居民 → 在工坊／武器坊補充器具 → 無職居民自行走去拿取 → 工程師施工、守備兵前往防線 → 夜襲實際接近和攻擊 → 拾回廢料、修復、重新招攬失去身分的人。

A／D 移動，靠近目標按 E 或畫面「投入」；相同操作用於招攬、供應器具、建造、升級與充能。頭頂顯示費用與不可投入原因。一次按下只投入一次，不需要開分配視窗或手動指派每名居民。

| 場所／對象 | 投入 | 結果 |
| --- | --- | --- |
| 流浪者 | 1 廢料作為補給 | 補給落地，流浪者拾取後才成為居民 |
| 工坊 | 2 廢料 | 上架 1 把工程錘；居民自行拾取成為工程師 |
| 武器坊 | 2 廢料 | 上架 1 件守備器具；居民自行拾取成為守備兵 |
| 防線 | 3 廢料建造、4 廢料升級 | 工程師到場工作 3 秒完成；最多 2 級，生命 40／80 |
| 受損防線 | 2 廢料 | 工程師到場修復；等待中的工單不重複扣款 |
| 義肢爐 | 1 龍晶 | 騎士增加 20 點本輪不恢復的護盾 |
| 護民塔 | 1 龍晶 | 增加 1 次居民受擊保護；實際擋住攻擊才消耗 |
| 警鐘 | 免費 | 提早迎戰下一波，正在交戰時不會重複生成 |

每個器具架最多 3 件。同一個器具只能被一人拿走。工程師與守備兵不會反覆消耗庫存。守備兵使用符文投射攻擊，目前視覺仍為簡易器具示意。

## 居民受擊規則

只有敵人接近、完成預警並實際命中居民，且未被護民塔擋住，居民才失去器具與身分、退回流浪者。倒數結束、騎士受傷或資源不足都不會直接改變居民身分。被擊退者有短暫恢復時間，在倒下處附近徘徊（v0.0.64 修正：先前有工作的居民會沿用舊的野外漫遊錨點走回原處），仍可重新招攬、領取新的器具。

防線會攔住右側接近的敵人並承受傷害；騎士仍能穿越防線出去交戰。護民塔保護居民，不替防線或騎士承傷。騎士可用既有劈砍與衝刺親自攔截敵人。

## 試驗範圍與完成條件

預設 14 廢料、3 龍晶、3 名流浪者；首次夜襲 55 秒後，三波分別 3／4／5 名敵人。波間有 30 秒整備時間。敵人被擊敗掉落 2 廢料，玩家靠近才拾取；離開的敵人不掉落。三波結束顯示試煉結束，居民與防線保留當時狀態，不把全員流失當成勝利。

這是單場、單側防守的可玩原型，R 重試清空本輪。沒有寫入原本訓練場的廢料存檔，沒有永久居民進度、農業、工具掉落再撿、工坊擴建或正式日夜系統。既有選單分配場景保留作歷史比較，F5 的避難所入口已指向新場景。

接下來觀察：玩家是否能不看長教學就理解投入；等待居民走路與施工是否舒服；職業、庫存與受擊結果是否能看懂。這些試玩結果優先於增加建築數量，角色動作細修依使用者要求暫緩。
