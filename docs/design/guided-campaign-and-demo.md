# 主流程引導與獨立 Demo 發行
2026-10-18，使用者授權實作。v0.0.56；v0.0.60 改為完整森林 Demo 並加快引導。

## v0.0.60：完整森林 Demo 與引導節奏
使用者試玩 Demo 後回報：引導太慢、沒有工匠封門打龍、沒有龍晶商人、沒有探索解謎拿部件、地圖鎖小，無法體驗資源流。原因是 Demo 使用 v1 核心試玩設定：`resolve()` 關閉商人、遺跡、戰馬與航行，刪除關卡設計參數（只剩小營地），兩夜後結束。

- 新 Demo 旅程使用主流程模式 v3（`core_loop_version=3`）：與主遊戲 v2 相同的引導與完整森林（關卡設計、野外事件、遺跡變化、巨龍開場、左右龍門），唯一差異是 `voyage_enabled=0`。打倒森林巨龍並清除殘敵即勝利；沒有火箭、星圖或其他星球。驗證規則只允許 v2 帶航行、v1／v3 不帶。
- 森林設定由 `journey_setup.create_forest()` 以與七星旅程第一顆星完全相同的步驟建立，不依賴 Demo 包中被裁掉的其他星球設定檔。
- 讀檔時 v3 紀錄不升級成七星封套；Demo 版接受 v3 與舊 v1 紀錄、拒絕七星紀錄。紀錄清單以 `forest_demo` 標記列出。舊 v1 兩夜紀錄照原規則續玩（含完成後仍可重試）；v3 與主遊戲一樣在教學兩夜後退役準備點。
- 勝利收尾在 Demo 版多一行說明完整版還有六顆星球與六條巨龍。
- 共用節奏：右牆完工並下令弓兵即開始首夜預警，20 秒（原 45 秒）；弓兵尚未到位時黃昏停在剩 3 秒，不在無人防守時入夜。新 Demo 的日夜沿用旅程節奏（遠征 180／60 秒），不再使用 v1 的 300 秒白晝。
- 理想玩家量測（`tools/measure_guided_pacing.gd`，同一套操作）：右牆完工到首夜 65→23 秒；Demo 到第二夜開始 506→349 秒；主遊戲 391→349 秒。真人初次遊玩時間仍待實測。

## 玩家流程
主遊戲從「開始旅程」、Demo 從「開始森林冒險」直接進入森林成果式引導，不需另開練習紀錄。首次採集交付後解鎖防線，右牆與弓兵到位才預告首夜；首夜結束開放完整森林服務、升級、遺跡及探索。第二夜結束後保留同一個營地、資源與居民，繼續封門、屠龍與七星旅程，沒有完成畫面或傳送到另一張圖。
引導可隱藏與重新顯示；略過文字不代替實際採集。新主旅程共用龍晶數字、用途費用、免費左右／固定塔位調動、普攻免費與移動恢復衝刺。後續星球直接使用這些操作規則，不重播森林教學。舊紀錄仍依原設定續玩。

## 地圖與平衡
主遊戲保留原有遠方地區、封印門、遺跡與商人。起始營地補上與demo共用的六處採集點、四位居民、左右牆及固定塔位；外圍拓荒建地依合併後節點重新建立，避免錯誤索引。兩夜預警與敵數來自core_loop.tres；後續敵潮恢復主旅程原有逐夜成長。森林樹木收益4、近郊安靜補給8。Demo白晝300秒／夜55秒；主遊戲保留選擇的旅程節奏（遠征森林180秒／60秒），首夜準備與45秒預告仍由完成條件啟動，兩次引導夜敵數固定，之後依旅程節奏增援。
主遊戲已有弓兵的左右配置跟隨完成的最外防線。兩個固定塔位需實際弓兵；外圍舊塔維持原功能。手機真機與擴張後戰鬥平衡仍待觀察。

## 完整重試與相容
CP1、CP2沿用完整還原。主遊戲的準備點只在森林教學期間提供；教學兩夜結束即退役，避免很久之後誤回初期。主遊戲重試仍保有七星封套。Demo在兩夜完成後仍可重試CP2。
快照結構仍v22；core_loop_version=2明確區別新主流程，v1仍是舊核心試玩，無標記是舊主旅程。未知模式、損壞快照仍拒絕讀取；讀舊檔不重排地圖、不注入教學。主包保留歷史桌面user目錄，Demo另用資料目錄與應用識別碼。

## 支線與實體打包
- main/develop：共同玩法和完整主遊戲；distribution.json預設full。
- demo：長期對外試玩支線，只覆寫distribution.json為demo；每次共用功能先合入main，再將main合入demo。禁止在demo複製另一份玩法實作。
- 發行前核對main與demo遊戲程式、資料、翻譯完全相同；差異只在預設發行設定。
- 暫存匯出樹刪除其餘六星的planets/levels/trails、專用敵人資料與圖像、星球場景素材；裁切資源目錄與固定預載。森林開場保留建設／戰鬥／巨龍鏡頭，省略六星掠影。
- 分別標示Main與Demo；Demo為完整森林冒險（v0.0.60 起，不出航）、獨立存檔、不列主遊戲入口、不接受七星紀錄。
- 同版Release發布兩套五平台附件；Pages根目錄使用Demo Web，完整Web獨立下載。規格書完整記載兩版邊界；Demo附專用三語短指南。
- 掃描成品PCK確認六星資源不存在，並操作裁切後入口；光隱藏按鈕不算完成。

## 驗收
新主旅程實際收入→首夜→兩條第二夜投資→同營地繼續→存讀→真實跨星交易；後續星球不重播引導。既有核心試玩仍兩夜終止，舊旅程保留原規則。Demo隔離目錄及拒絕主紀錄；五平台同來源／版本／分包名、包內資源及公開站雜湊分別記錄。真人初次理解、10–15分鐘分布、Windows及手機真機不以自動測試代替。
