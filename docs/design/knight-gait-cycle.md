# 騎士雙步循環與速度銜接

> 歷史版本紀錄：目前人物素材與動作重製以 [v0.0.50 設計](knight-motion-remaster.md) 為準。

修正騎士走跑缺少完整換腳、腳步頻率與移動不一致的問題。四套持劍／徒手走跑改為16格雙步循環，固定同一人物比例及腰胯錨點；疲勞慢走沿用較低步頻。走跑、方向及持劍狀態共用步態進度，腳步按實際速度推進；移速、體力、攻擊與快照v20／航行v2不變。

## 問題與處理

v0.0.47 的12格原稿不是完整左右雙步：多格維持相同前腳，缺乏穿越支撐腳的過渡。按頭部亮點逐格對齊又使腰胯位置不穩。程式對較慢移速仍用固定步頻；16格改稿不能直接沿用原先12格的時間換算。

保留黑鋼、黃銅、紅披風造型，重畫持劍／徒手各16格步行與16格快跑。四套共用單一比例、128×96圖格和來源圖格中的固定腰胯位置；不逐格拉伸、不拆手腳。步行直立、快跑前傾並抬腿，兩套都包含落腳、承重、經過支撐腿、換腳。慢走直接使用步行圖格，降低頻率。

`knight_stride.gd` 保存0–1的雙步進度，以移動速度和遊戲時間推進。換方向、步行／快跑／疲勞與持劍狀態不重置進度，零遊戲時間或零速度不推進。只套用有參考速度設定的騎士 Resource；舊獨立原型沿用原播放方式。移動與攻擊規則、鎖定時間及存檔內容沒有新增欄位。

## 調整位置

`data/hero_v005_appearance.tres` 保留整套騎士入口，移動圖片指向 `art/characters/hero-gait-v006/`；其餘出刀、受擊、騎乘等素材沿用v47。參考速度165／321.75／69.3時，步行／快跑／疲勞為28／36／16格每秒，每個完整雙步16格。其他實際速度按比例調整，這些是動畫參數，不會改變角色移速。

`tools/prepare_hero_gait_v006.gd` 使用v005整理器的可指定來源／欄數／目的地介面，裁出完整姿勢，再以共同倍率、固定腰胯錨點落到原生網格；`tools/build_hero_resources.py` 寫入圖格與接點。原稿與內建imagegen提示保存在 `art/concepts/hero-gait-v006/`。

## 驗收

用實際場景／公開呈現介面檢查同距離腳步一致、停住／暫停凍結、走跑及疲勞切換不跳腳；先紅4處、再綠12項。另用原生遊戲連續輸入錄下左右、持劍／徒手、疲勞循環，觀看正常速度與半速。完整回歸與同源成品仍依發行程序驗收；不把產圖張數或匯出成功當作動畫順暢的證據。
