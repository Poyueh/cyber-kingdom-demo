# 電漿鬼魂與狩獵生物

v0.0.68 鬼魂重製為較小的賽博電漿夥伴：青藍核心、電路節點、分段電容光環與短尾流；穩定的本體不做閃爍，只讓周圍能量緩慢呼吸。保留帶路、回頭、招手與警戒，沿用少量目標短句；避讓以實際提示框邊緣找安全位置，與繪製共用30×34半尺寸，不再因有限候選點都被擋住就反覆整隻隱藏。引魂壇共用新造型；主遊戲、Demo及既有旅程都使用新版呈現。

v0.0.68 可狩獵生物包括鹿、野兔與野豬；野兔／野豬使用原生兩像素網格、依實際移動推進腳步，停下及暫停不滑步。新主旅程與Demo森林近郊左右各三隻，遠處森林補給區每區三個固定獵物位置；不增加謎題或事件點。獵人照原工作範圍白天狩獵、提前回城，每次成功仍為2晶。只在真實日出、有棲地時恢復既有獵物位置，不逐幀增生；砍光森林不再恢復。wildlife_version=1與數值保存於建立時設定，快照仍v23；無標記的舊存檔保留原數量與生死狀態，僅套用新外觀。

呈現問題調查：一般寬螢幕沿路移動600個採樣未消失；密集／寬提示區可以重現舊版七個候選位置全部被擋、view整隻隱藏。以原版腳本重播同一場景失敗，新版改為實際邊緣與安全區候選並縮小輪廓，同一場景通過。只有真正沒有安全空間時才保留隱藏保護。

數值：data/spirit_companion.tres；新旅程獵物：data/wildlife_population.tres。狩獵不新增角色控制、互動或任務。人口與採集資源規則不變。採用獨立配置標記避免讀取舊森林時改變動物陣列長度；新增族群不消耗其他玩法的亂數。

驗收：先確認新森林兩隻獵物及遠林無獵物的失敗案例，再確認近郊6隻、遠林、相同種子、JSON續玩、日出恢復不增殖、舊檔不插入動物及損壞資料拒讀。造型及動畫以原生場景錄影驗收，手機真機仍待試玩。

實景校對：小型獵物的繪製置於建築底座之前；電漿外暈使用低透明度階梯橢圓，不使用矩形光塊。
