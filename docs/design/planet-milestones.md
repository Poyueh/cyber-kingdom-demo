# 星球功績與領核演出（v0.0.33）

## 玩家問題與目的

原本領取龍核只有短暫寶箱特效，星圖無法回顧每顆星球的探索或建設成果。本次讓玩家辨識遠征的一個階段已完成，知道真正開啟了哪些航線，也能自行決定留下完善聚落或啟航。

## 實際行為

- 龍核領取後短暫顯示星球名稱、已取得核心印記與新航線；晶體飛入七核列。沒有新航線時提示可重建火箭或繼續當地功績。第七核直接沿用通關演出，不重疊兩次音效。
- 星圖選擇已到訪星球，顯示荒野探索（已揭露區域／總區域）、遺跡破譯（已解機關／當地總數）、聚落建設（營火階段／三級）。森林遺跡包含戰馬導流核心；攜帶戰馬到別的星球不會算成當地解謎。
- 三項各自完成後印記轉金色。它們均為選做回顧，不給額外龍晶、不改變通關／航線要求，不鼓勵為領獎重複刷取。
- 未到訪星球不透露功績數量或隱藏內容。離開星球後直接讀既有已驗證快照，不啟動該地的居民、時間或採集模擬。
- 提示約六秒，暫停凍結並隱藏，讀檔或返訪不重播。常駐遊戲 HUD 不增加任務清單。三語均有相同資訊。

## 維護與存檔

application/voyage_progress.gd 只回傳 UI 唯讀資料；presentation 的星圖、印記與演出各自消費它，bootstrap 接線。時長、飛行與淡出由 data/planet_feedback.tres 調整。只有實際領核產生新的音效事件；沒有新增存檔欄位，快照仍 v19。

## 驗證與後續

TDD 先重現領核事件、功績投影與新航線資訊缺口，再接到原生場景。驗收包括實際 E／下滑領核、七地航線、未訪隱藏、三語尺寸、暫停、讀檔、舊版套件存檔與相同續跑結果。英文面板曾超出手機邏輯高度，已縮短預覽圖及調整欄寬修正。

這次驗證證明操作與資料一致，不證明真人心流、留存或商業成績。後續觀察玩家領核後是否理解新航線、是否自願返訪、是否把選做印記誤認為必須刷滿；若形成壓力，應弱化印記而非再添獎勵。
