# 旅程節奏在建立時解析並保存

狀態：已採用，v0.0.29。

玩家能選不同的白晝與夜襲壓力，但不能因平衡資源更新或回到已探索星球而悄悄變難。資料層以 Resource 提供選擇，application/journey_setup 在各星球規則合併後一次解析數值；之後完全使用原有戰役時鐘與敵潮，不增加每幀乘數或隱藏的動態難度。

實際數值及旅程標記保存於既有設定封套。讀檔驗證標記合法、七地一致，但不從 Resource 重算保存值。沒有標記的舊旅程沿用原設定；不回填成另一種難度。代價是修改 Resource 只影響新旅程，Inspector 教學與玩家說明必須說清楚。

v0.0.36 將同一決策延伸到七地關卡。可編輯區段配置在建立時解析成平坦數值設定，新增 level_design_version 及地區用途，沿用既有快照封套，不增加 session 可變欄位。地區用途以設定為準，讀檔驗證與生成結果一致；不同版本的旅程不混用，舊星球維持原本 20 區配置。LEVEL_LAYOUT 亂數流只追加於既有流末端，不改動舊流索引或鹽值。
