# 皮革龍晶袋 v001

2026-09-21 以 Codex 內建 imagegen 產生原創開口皮革袋：暖褐紅皮革、舊黃銅波浪袋口、繫繩、菱形扣，透明背景，不含龍晶和文字，清楚的小尺寸像素輪廓。參考使用者要求的精緻像素遊戲質感，沒有擷取既有遊戲素材。

sources/purse.png 保留原圖並以 .gdignore 排除引擎匯入。依既有本機處理授權，alpha >=150 保留，裁去透明外邊，以最近鄰縮至80×80內並置中。crystal_purse_view.gd 在袋口疊畫龍晶，依滿度顯示；收支時短暫變形，滿袋有微弱亮點，無數字。

畫面安全區右下角96×96，底部和右側保留16像素；手機劍按鈕左移112像素避開袋子。
