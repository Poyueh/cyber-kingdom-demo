# 黑鋼騎士重設提案

使用者否定舊騎士整體造型與動作，要求重新設計。本提案使用 **Codex 內建 image_gen** 產生新設計，不是修改舊銀甲角色的局部角度。

## 已交付

- `sources/design.png`：新造型與十二個動作關鍵姿勢。黑鋼輪廓、銀邊、青色目鏡、單側龍晶義臂、深紅披風。
- `sources/run.png`、`sources/slash.png`：各八格動作草稿，完整保留原始輸出。
- `sources/balanced-run.png`：依角色設計與骨架姿勢參考重新生成的全身稿，保留原始輸出；生成格的左右腿仍有錯誤，沒有直接當作可播循環。`sources/pose-guide.png` 是本次生成使用的姿勢藍圖。
- `preview/index.html`：可切換造型／跑步／斬擊、暫停、半速和逐格查看，含 3× 與原生尺寸對照。
- 預覽現在預設停在「生成原圖 · 16 格」第一格，直接裁切 `sources/balanced-run.png` 並等比例縮放，不拆件、不改姿勢、不減色；保留「重組實驗 · 24 格」作明確區隔。頁面顯示完整原圖及連結，避免把生成畫面的品質與重組結果混為一談。原圖的位置抖動、同側腿重複也如實顯示，不能稱為完成的遊戲動畫。
- `prepare_preview.py`：依使用者既有本機修圖授權，清除低 alpha 邊缘與鄰格碎片、最近鄰縮至約 60 像素高、32 色與固定腳底；沒有以模糊插格或人物殘影假裝動作流暢。
- `animate_run.py`：使用新的全身稿，離線重製 **24 格交替跑步**。腿長與新原圖相近，腿甲寬度保持固定；腳底超過可及範圍會直接報錯，不拉長腿甲補洞。每隻腳依序落地、承重、蹬地、收回，遠側腿错開半個循環並降低亮度。肩腰共用重心軸，上身收回過度前趴角度，加入自由手擺動和披風延遲；整套共用 32 色調色盤。
- `preview/run.png`：6 欄 × 4 列，每格 128 × 96，36 fps、約 0.667 秒一個左右腳完整循環。`preview/run-steps.png` 提供六個關鍵姿勢對照。原始八格 `sources/run.png` 不覆寫。
- `prompts.md`：採用的角色設計摘要和兩套動作最終提示詞。

## 審查結果與範圍

這是**造型及動作設計階段**，不是整套正式動畫或遊戲更新。第一版 24 格被玩家指出上下身不平衡：腿甲比來源拉長、腰部上移，軀幹卻只保持單一前傾姿勢。現改用新全身稿、接近來源的腿長與一致的肩腰重心，保留交替步態並加入擺臂和披風延遲。這是生成原畫加離線部件動作校正，不能稱為逐格手繪。斬擊仍缺少高速出刀的中間姿勢，跑步也仍需玩家確認美感；接入 Godot 前須補齊其他狀態，避免新舊騎士混用。

目前 `frontier.tscn` 和正式動畫資源均未改動。此資料夾根部 `.gdignore` 防止造型原圖進入 Godot 匯入／遊戲包；預覽獨立於 H5 遊戲。沒有推送或發布線上版本。

另產生過一張密集移動草稿，沒有遵守 4×8 格要求，未採用也未放入本專案。保留的八格跑步原圖僅作歷史設計來源，現行預覽改用新全身稿製成的 24 格圖集。

重建：使用有 Pillow 與 NumPy 的 Python 執行 `prepare_preview.py`。步幅、抬脚、靴子角度集中在 `animate_run.py` 的 `FOOT_KEYS`；這些是美術產製參數，不是遊戲速度或戰鬥規則。工具輸出不在遊戲執行時運算。

在此資料夾開本機 HTTP 伺服器，瀏覽 `preview/`；目前 http://localhost:8805/preview/ 。
