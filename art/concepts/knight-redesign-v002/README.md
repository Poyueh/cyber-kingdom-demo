# 黑鋼騎士重設提案

使用者否定舊騎士整體造型與動作，要求重新設計。本提案使用 **Codex 內建 image_gen** 產生新設計，不是修改舊銀甲角色的局部角度。

## 已交付

- `sources/design.png`：新造型與十二個動作關鍵姿勢。黑鋼輪廓、銀邊、青色目鏡、單側龍晶義臂、深紅披風。
- `sources/run.png`、`sources/slash.png`：各八格動作草稿，完整保留原始輸出。
- `preview/index.html`：可切換造型／跑步／斬擊、暫停、半速和逐格查看，含 3× 與原生尺寸對照。
- `prepare_preview.py`：依使用者既有本機修圖授權，清除低 alpha 邊缘與鄰格碎片、最近鄰縮至約 60 像素高、32 色與固定腳底；沒有以模糊插格或人物殘影假裝動作流暢。
- `prompts.md`：採用的角色設計摘要和兩套動作最終提示詞。

## 審查結果與範圍

這是**造型及動作設計階段**，不是整套正式動畫或遊戲更新。生成跑步的若干姿勢仍過近、交替腿不夠明確，斬擊缺少高速出刀的中間姿勢；不能聲稱已完成優於舊版的連續動畫。下一步需補畫、實際播放驗證後再接入 Godot，並補齊三段連斬、踏斬、拔劍、喘息和騎乘，避免新舊騎士混用。

目前 `frontier.tscn` 和正式動畫資源均未改動。此資料夾根部 `.gdignore` 防止造型原圖進入 Godot 匯入／遊戲包；預覽獨立於 H5 遊戲。沒有推送或發布線上版本。

另產生過一張密集移動草稿，沒有遵守 4×8 格要求，未採用也未放入本專案。八格跑步草稿雖可正確切格，仍有上述動作品質限制。

在此資料夾開本機 HTTP 伺服器，瀏覽 `preview/`；目前 http://localhost:8805/preview/ 。
