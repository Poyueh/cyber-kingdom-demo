# 黑鋼騎士 v005 原稿與提示

使用內建 `image_gen` 生成18張透明背景動作原稿，共224個全身姿勢。`sources/<name>.prompt.txt` 保存逐張完整提示；同名PNG是工具原圖。`manifest.json` 保存使用的工具與參考來源。遊戲不直接載入這些高解析原稿。

姿勢：徒手／持劍 support各16、跑步／快跑／慢走各12×2、拔劍8、騎乘16×2、六套原地／踏斬12×6、空中8。未以程式拆開身體、拼手腳或合成新的美術姿勢。

## 重建原生素材

1. Godot 執行 `--headless --path . --script res://tools/prepare_hero_v005.gd`。
2. 執行 `python3 tools/build_hero_resources.py`，將圖集與肩甲錨點寫入資源。
3. Godot 匯入並以實際場景確認。整理器只做透明雜點清除、連通區裁格、全段固定倍率最近鄰縮放與排列；原稿不覆寫。

遊戲原生圖集在 `art/characters/hero-v005/`，參考站高60像素，一般128×96／大型动作160×128。`metrics.json` 記錄每套固定比例、界限和腳底；`sockets.json` 保存逐格肩甲接點。全段共同比例保留重心起落，不做逐格拉伸。

原生實錄與畫面見 `docs/reports/hero-v005/`。生成素材仍可能有微小逐格細節差異；流暢度以實際遊戲回饋持續調整，不以原稿格數代替遊玩驗收。
