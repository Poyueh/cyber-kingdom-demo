# 三星球素材來源

使用 Codex 內建 imagegen 產生：沙地／冰岸遠景、沙龍／冰龍各四姿勢、八個地表物件、火箭三階段，共六张生成原稿。沒有使用外部搜尋圖片或 imagegen CLI。

精確提示詞與原稿保留在 `sources/`；該資料夾有 `.gdignore`，不進遊戲素材包。使用者先前已允許以本機工具做透明清理及切格。

`tools/prepare_planet_art.py` 以 Pillow／NumPy 裁透明連通區、共同縮放和最近鄰切到原生網格，生成 `art/planets/v001`。巨龍四姿勢同一比例、腳底基準固定，避免鄰格尾端滲入；火箭三階段也共同比例。前景在遊戲內以 1:1 原生像素繪製。
