# Rescue ship source

Generated with the built-in image_gen tool; exact prompt in prompt.json. The top is wrecked and the bottom repaired. Original alpha is preserved. tools/prepare_rescue_art.py only thresholds fringe alpha, samples both frames at one fixed native pixel scale, and packs a 384×224 atlas with shared (192,106) ground pivot. Runtime uses the native atlas at 1:1. Sources stay excluded from exports.
