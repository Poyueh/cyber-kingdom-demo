# 四地貌與巨龍素材

使用內建 image_gen 工具製作四張原始圖集：孢潮沼澤、熔脊裂谷、雷纜廢都、黯潮墓環。完整提示詞與原始工具輸出路徑保存於 prompts.json，原稿保存於 sources/。

依使用者既有授權，以 tools/prepare_seven_planet_art.py 在本機統一透明 alpha、裁格與最近鄰縮小到原生像素網格。每隻龍四格 320×224 共用縮放和脚底基線；沒有在執行時讀高解析稿。地面左右鏡像銜接，正式素材位於 art/planets/v002/。原稿保留且不進遊戲匯出包。

這些是本輪新製作的可玩素材，不代表已達到手繪完整逐格精修或商業最終美術品質。
