# 騎士交替落腳步態 v001

沿用 stride-v001 的銀色頭盔、上身、紅披風及拖劍原圖，重新製作金色機械雙腿。原始圖片保留在上一版資料夾；本版沒有重新生成整個角色。

armed.png 與 unarmed.png 各為 1024×192，8 欄×2 列，共 16 格，每格 128×96。左右腳相差半個週期；支撐腳固定地面高度向後推，擺動腳向前抬起。髖部有 1 像素重心變化，披風隨步態擺動。動畫兩端循環連續，腿甲前後採不同明暗。

## 重建

使用安裝 Pillow、NumPy 的 Python 執行 `sources/process.py`。腳本以兩節腿部關節離線繪製像素腿甲，輸出 atlas、姿勢資料、接觸表及 GIF。沿用玩家授權的本機素材處理流程；sources/.gdignore 排除加工素材，遊戲只載入兩張 PNG，沒有逐幀建立圖片或執行關節求解。

步行／快跑的預設播放率為 24／56 fps，完整循環都是 16 格。可在 KnightVisual Inspector 調整 walking_frame_rate、running_frame_rate；遊戲速度和體力規則沒有變更。GIF 固定 42ms，僅用於檢查姿勢，實際遊戲以移動速度平滑調整播放率。
